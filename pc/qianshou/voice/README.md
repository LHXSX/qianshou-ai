# Local ASR resource preparation

English | [中文](README.zh.md)

This directory prepares pinned whisper.cpp and small-q5_1 resources. It does not change the global environment, older projects or user configuration, and does not download a neural narration model. The script requires macOS arm64, Python 3.12 or later, and existing CMake and Xcode command-line tools. Device microphone authorization and human speech recognition require separate acceptance.

Choose an explicit absolute private directory (0700, owned by the current user). Run `python3 -B qianshou/voice/prepare.py --root /absolute/private/asr --check` to check prerequisites, then omit `--check` to download and compile. `--jobs` defaults to 4 and accepts 1–32. The script installs no dependencies automatically; it writes downloads, sources, build products, licenses and `manifest.json` only inside the specified directory. The model is approximately 190 MB and compilation needs additional space. Existing resources must still match the lock; any byte-count or SHA-256 mismatch is rejected without overwriting user files. An installation lock prevents concurrent writes to that directory. The owner must inspect sources or build products left by a failure; the script does not delete them automatically.

After preparation succeeds, explicitly pass the manifest's `binaryPath` and `modelPath` to the Host `qianshou-voice` configuration. Without configuration, the UI reports unavailable resources and does not claim completed recognition. Source and model pins live in `asr.lock.json`. Resource updates must update the lock, licenses and real recognition acceptance together; they do not track upstream latest. If a download fails, a complete file from the same official URL may be placed in the same directory's cache before retrying, but it must still pass the original lock. Do not disable TLS verification or change the lock to accept incomplete content.

`licenses/whisper.cpp.LICENSE` comes from the pinned whisper.cpp source, and `licenses/Whisper.LICENSE` contains OpenAI Whisper's MIT license. The pinned model card declares MIT. Deployments or distributions must retain both licenses and the resource lock. The source and pinned model card are available at [whisper.cpp](https://github.com/ggml-org/whisper.cpp) and the [pinned small-q5_1 repository](https://huggingface.co/ggerganov/whisper.cpp/tree/5359861c739e955e79d9a303bcbc70fb988958b1). Model weights are not committed to this repository.

Ordinary code tests use controlled local processes and do not download models. Actual recognition uses explicitly labeled offline system-synthesized or official audio and records the WAV hash, audio parameters, model hash, recognized text and elapsed time. That result verifies only the installed local ASR. Human microphones, other operating systems, packaged installation and noisy audio quality are outside that result.
