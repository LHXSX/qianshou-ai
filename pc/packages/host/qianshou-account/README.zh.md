# @deepseek-ai/dsh-host-qianshou-account

[English](README.md) | 中文

## 概述

本私有插件在单个 Host 内拥有千手账号生命周期。上海是身份权威；广州使用其用户访问令牌访问模型目录和模型请求。Remote 响应仅包含身份、状态、安全错误码、模型标识和路由选择。密码、令牌对和待完成的 TOTP 挑战不会出现在该响应或对话历史中。

## 配置与使用

千手 Web 组合仅在 `qianshou` 构建配置下启用此服务。`accountOrigin` 默认为 `https://qianshousuanli.com`，`gatewayBase` 默认为 `https://app.qianshousuanli.com/api/qianshou/ai`，`timeoutMs` 默认为 15000。除本地回环集成测试外必须使用 HTTPS。请求拒绝重定向且不携带 Cookie。

[账号界面](../../client/ui-qianshou-account/README.zh.md) 调用生成的 `qianshouAccount` Remote。密码和 TOTP 登录调用上海 `/api/v8/auth` 端点；手机号登录调用已有的 `/auth/sms/send` 与 `/auth/login/phone`。已登录后的订阅与充值读取广州 `POST /status` 和上海钱包、报价、购买接口，并用 `POST /payment/recharge` 发起支付宝充值。重新连接按需续期、验证 `/auth/me`，并用 `POST /models` 读取广州目录。缺少刷新令牌时表示为仅本次有效的登录。厂商密钥不能生成普通用户身份。

密码登录完成、TOTP 登录完成，以及启动时恢复到已有会话，都会选中 `qianshou-cloud` 并把它设为默认模型。其他提供方条目和权限设置保持原状。默认模型适用于新会话以及未明确选择模型的既有空会话；已经选过模型或已记录请求的会话保留选择。`useCloud` 会再执行一次同样的选择。选择器只发布一行，显示名是千手v4；请求仍使用目录中的第一个标识，这一行接受文本和图片输入。其余目录标识留在账号状态中，不成为额外的选择器条目。本地路由为计量和压缩记录 1000000 token 的窗口；广州仍按登录账号的档位准入每一次请求，并将输出预算压到模型公布的上限。已登录的每一轮直接把完整对话和所选预设的工具说明送入文字模型；本包不再先用本地预览或广州 `/intent` 给单句分类。本包没有模型可调用的出图工具；经过验证且有授权控制的能力工具安装并实测前，不能把旧的直接出图路径说成可用。

## 凭据与生命周期归属

Host 将第一版刷新凭据保存在 `qianshou-account/session`，将托管访问引用保存在 `QIANSHOU_ACCOUNT_ACCESS_TOKEN`。它不会覆盖旧 `QIANSHOU_ACCESS_TOKEN` 引用或其他提供方密钥。当前开发凭据提供方使用权限受限的明文文件，并非系统钥匙串。访问令牌轮换通过提供方正常的逐请求凭据解析生效。

更换登录、取消、退出及销毁都会中止当前账号生命周期。pi-ai 传输准入钩子将该生命周期接入托管千手模型调用，包括已经开始的 HTTP 响应。其他提供方和手工配置的旧千手密钥不受影响。本账号服务不会自动重放付费模型请求。

代际检查拒绝迟到的登录与续期响应。续期采用单飞请求，持久写入串行执行。销毁等待待完成写入及补偿清理结束，之后才允许新所有者挂载。HTTP 429 和服务端或网络故障保留续期凭据；身份被拒绝时清理凭据。退出时即使只读环境引用阻止移除托管访问引用，也会先删除本插件的刷新凭据，并展示安全的存储失败状态。服务端注销可能失败，本地退出仍然有效。

## 模型体验

### 账号展示与路由准入

#### 模型看到什么

`qianshouAccount` Remote 是主人界面接口。本账号插件不提供面向模型的任务工具。模型会看到完整会话，包括上一轮问题的简短回答；它只能调用当前预设实际挂载的工具。能力能否执行由该工具及 Host 准入决定，路由预览不能执行或扣费。未登录或网关地址与账号绑定地址不一致时，模型请求仍在发送前被拦下。账号取消会传播到提供方中止信号并产生已中止的模型结果。当所选预设提供 Bash 或 PowerShell 时，即使市场算力执行器目录为空，普通工作目录任务仍可继续使用已有工具；工具自身的权限和依赖检查继续生效。这不会注册远端提供者、授权收费订单，或声明模型已经就绪。

#### Token 影响

账号操作与界面展示不会发起模型请求或增加提示词 token；后续对话使用明确选定的模型路由。

#### KV Cache 影响

本包不重写既有消息，也不注入隐藏提示词前缀；缓存行为由选定模型提供方与普通对话流程决定。

## 已知限制与后续工作

<a id="doc-section-4"></a>

- 本包测试使用受控账号响应、真实 Cordis 服务、内存凭据及设置，以及真实本地回环 HTTP 模型流，覆盖登录与 TOTP、过期、并发续期、迟到结果、销毁重建、存储归属、显式路由选择和活动传输取消。这些是本地开发检查，不代表上海真实用户登录或广州付费推理正向验收。真实账号验收需要真实用户身份；系统钥匙串及正式发布登录体验属于独立发布工作。

本包不发布运行时 invariant 伴随插件：服务拥有单一账号状态机，凭据写入和取消生命周期通过该所有者的生命周期测试验证。
