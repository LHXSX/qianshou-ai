# Mac 本机绘制视频候选执行器

[English](README.md) | 中文

`createMacDrawnVideoExecutor` 是一个源码层的 `ComputeExecutor` 工厂，在 macOS 本机绘制五秒海边骑车动画。它用 AppKit 绘制 1280×720、24 fps 的 120 帧，以 FFmpeg 编码 H.264/yuv420p，再核对视频流、时长、帧数、完整解码、文件大小和 SHA-256。它不调用模型、网络，也不执行任务提供的代码。

任务只接受 `title`（1–16 字符）和 `subtitle`（1–32 字符）。两者写入仅机主可读的私有 JSON 文件，交由固定 Swift 程序读取；文件输入和其他参数均被拒绝。这是带海浪、车轮和骑行者运动的绘制场景，不是通用文生视频。由机主选定的安装配置须提供精确的能力 ID 与版本、Swift/FFmpeg/FFprobe 的绝对路径和运行时间上限。此工厂不会自行注册、安装市场包、打开接单或授权任务。

输出引用指向私有任务目录，路径是临时的，须在任务目录清理前完成消费。只有获授权的结果消费方将 MP4 复制到持久路径并核验后，才能在对话里提供 `[播放视频](/absolute/persisted/video.mp4)` 这样的链接。本机执行通过不代表上海派单、市场审核、签名、定价、机主授权或结算已经完成。
