# @deepseek-ai/dsh-client-ui-plugin-manager

[English](README.md) | 中文

## 概述

使用 Web 侧栏的**插件**入口管理 profile 已安装的组合包，以及安装随附、默认关闭的可选组合包。可以启停组合包及其行、在 Host 读出 spec 指向什么之后安装组合包、查看 pnpm 输出、停止一次运行，并启用它新增的包。卸载会要求确认。注册了配置页的插件在这里、在它自己的页面上编辑；设置里只保留只读的插件列表。

## 使用本包

在侧栏选择**插件**。页面首次打开时通过 `api-remotes` 读取清单与组合包；没有受管 profile 的 Host 上页面显示为不可用。**随应用提供**列出安装附带的可选组合包，**我的插件**列出当前环境安装或无法读取的已选包，**功能设置**列出已注册的配置页。来源分组表示安装归属，不代表发布者认证。启停不会改变卡片顺序；内置 profile 组合包仍从设置中的清单查看。

本机搜索匹配完整包名、本地化名称和描述；配置页匹配 id 或名称。状态筛选只针对插件卡片，筛选期间隐藏配置页。打开详情或刷新后保留筛选条件。加载摘要区分已加载、异常、等待、加载中、卸载中及没有组件观察结果；已保存启用选择不代表组件已加载或业务能力可用。千手 profile 的侧栏「技能中心」默认打开「技能市场」，继续使用既有 `plugins` 路由；其他 profile 保留「插件」入口并默认显示本机插件。

Agent Teams、Agent Teams Web UI 和 Auto Authorization Review 三个包使用随界面语言切换的本地化名称和描述。详情页保留完整 npm 包名；其他包显示简写包名和原始描述。

千手中的随附 `dshmarket` 包及其 `dsh-market` 组件也使用「技能中心」显示名；技术身份、商品来源描述与独立的本机插件发现入口保持原样。其他 profile 保留「插件市场」显示名。

### 插件市场

`@市场/` 打开真实市场目录，不进行文件系统发现。发送目录或未选完的分类会保留草稿并提示选择具体能力，在普通模型收到消息前拦截；只有当前目录中选定的实际条目才能进入已有询价流程。

任务参数表单保留服务端声明的数值范围，上限不超过安全整数范围，包含模型使用的 32 位随机种子。纯文本请求在询价前遵守声明的字符数限制。 旧版已审核 JSON 合同未声明内容字段时，使用原始 JSON 输入框，遵守实际字符数限制与 16 KiB 输入上限。输入须为非空 JSON 对象、数值有限且 Unicode 有效，随后服务器仍按签名执行合同校验。已声明但不支持的内容 schema 继续关闭，不降级为原始 JSON。客户端不按任务名称推测字段，询价也不等于确认付费派单。

在千手配置中，发送 `@能力名称 需求` 会在原对话调用已审核的市场合同。卡片保留需求、中央服务器执行报价、任务引用、进度和结果；询价只确认本地草案，不会收费派单。机主仍需单独确认显示的价格。报价回执将精确的草案与原请求能力绑定到当前目录中真实的落地任务类型。合同不可调用时保留输入草稿，并在进入普通模型提交前显示错误。

会话调用引用由声明的会话状态仓库保存在浏览器本地。切换对话或重新加载同一客户端后，各对话恢复自己的元数据与有界输入控件值；任务进度和结果从已认证的 Host 读取。未派单卡片根据恢复后的输入创建新本地草案并重新询价。修改任一输入或参数都会使旧草案与价格失效。已保存为待核查的提交只提供回执核查，不会自动重发。这份记录不跨设备同步，清除浏览器存储会移除本地引用。卡片不会将需求提交给普通模型，也不要求本机安装媒体运行环境。

市场需求通过共用的 `chatTimelineEntries` 注册表，按原提交时间插入既有对话消息之间。持久化会话 store 仍是唯一写入者，原内容入口只桥接时间线描述符和内容存在状态，卡片通过标准 useStore hook 共用同一声明的 store。进度与结果更新保留原位置；切走时撤销桥接，返回后重新激活同一会话 store，不新增模型轮次或伪造 Session 事件。卡片只显示服务端观察到的进度，无百分比时显示不确定进度条；任务完成后另行显示成果读取状态，诊断编号默认折叠。已验证文件提供绑定精确任务和摘要的同源手动下载，由 Host 获取新授权并核验字节；未知或不匹配引用不提供下载，也不自动预览 HTML。

历史卡片也通过标准注入 hook 读取实际市场目录。目录正在刷新、读取失败或已不再开放精确任务和能力时，保留显示的输入，暂停新报价与派单；已提交任务继续核对回执和读取成果。较早目录代际的迟到报价作废。

以下创意表单适用于市场中的具名视频商品和旧市场草稿；`@出视频` 快捷入口使用下述纯对话流程。旧表单从对话里的一句话需求开始。“轻松出片”会自动请本机 Host AI 智能体整理首帧建议和可编辑方案；补充问题收在可选详情里。首帧区最多预览三张真实本机 PNG/JPEG 图片。用户可以直接选图，也可以授权选择一个本机文件夹；PC 按文件名、文件夹名里的关键词挑出现有图片，不声称理解图片内容或生成新图。描述改变后需按新内容重新推荐，图片在浏览器成功加载后才能确认。浏览、回答和选图均不上传；确认创意也不等于确认付费。确认后才可由 PC 直传选中图片的快照，并核验 SHA-256 与对象版本。只有当 Host 当次目录提供已审核、明确首帧槽与描述槽且支持图片类型的公开视频合同，图文请求才允许询价；确认时绑定发布编号与合同摘要，审核版本、选图变化或预览失败使旧确认失效。Host 在询价和付费提交前重读精确审核合同。旧的固定首帧流程仍可按其独立的纯文字表单使用。目前没有经核验可用的远端生图或素材推荐合同；多个不同视频任务的自动选择也要等平台明确提供创作类型合同。

买家卡片区分等待中、失败的 AI 请求与带模型回执的本机 AgentLoop 方案。用户选定真实本机首帧后，会自动整理与图片 SHA-256 绑定的新方案；模型失败时保留文字与图片草稿供重试，不标为 AI 已完成。原始需求最多 4096 UTF-8 字节，每项可选补充最多 1024 字节；超限时保留原文并指出要修改的字段，不启动模型调用。上传前，卡片显示选中图片的格式、字节数和 SHA-256；核验上传后显示对象存储键和版本。只有当前已审核任务表单把必填整数 `frames` 固定为 120、`fps` 固定为 24，且最终可编辑描述没有以分钟简写或时钟格式要求其他时长，卡片才允许确认和报价；这两个值从表单自动填写。AI 输出不能保证最终时长，也不能证明已有在线执行设备。平台返回 `DONE` 而结果尚未就绪时，卡片每五秒只读重查状态，结果就绪后自动读取，不重新询价或派单。若已完成任务的结果读取失败，或回执任务身份、状态不符，卡片显示失败，并对同一任务每五秒最多自动只读重查三次；仍可手动重新读取，不重新询价或派单。平台返回 `DONE` 只报告任务完成，视频仍待核对可读取；只预加载元数据时，用户可能要点击播放才能触发浏览器 `canplay`。已认证同源媒体引用必须指向卡片对应的精确任务。`canplay` 只表示视频预览可播放，不等于完整成片、服务端签名验片或完整字节摘要核验；用户仍需根据平台验收回执播放核对全片。播放失败时可重试读取同一结果，不重新询价或派单，键盘焦点留在重试按钮；迟到的可播放事件不会清除同次失败状态。结果状态若与已完成任务不一致，卡片会拒绝展示；视频任务只返回文字、图片、WebM/MOV 引用或空结果时，提示尚无符合本次审核合同的 MP4并允许重新读取，不重复派单。首帧上传完成回执失败时，上传结果仍待核查，卡片只确认尚未报价、未派单。隔离中的视频结果若只有内联 JSON，买家不能确认结算，但仍可拒绝并退款；待验收回执与任务的隔离状态不一致时，不显示决策入口。

旧表单中的“轻松出片”显示已提交的一句话需求、AI 方案、核验过的首帧和买家确认，不强制回答主体、动作或风格问题；用途与声音可以跳过。旧“专业创作”表单增加剧情、镜头和希望避开的内容，但它们只组成已审核的文字描述，不直接改设备工作流，也不会自行构造未审核的负面提示参数。时长、比例、随机种子等独立参数只有出现在当前公开审核任务合同中才显示；必要参数在两种模式下都可见，切回轻松模式会恢复非必要参数的审核默认值并使旧报价失效。确认区显示最终描述和首帧，解释人民币单次报价与派单仍需单独确认；目录元数据不能证明本次能力所需的设备、模型或工作流已经就绪。缺少已审核图文合同则无法确认创意或继续询价。

私有视频试用未启用时，`@出视频` 快捷入口保留用户的对话原文，只显示一条简短的可用状态。入口没有轻松／专业选择、参数表单、AI 扩写或自动智能体调用。正式对话到出片适配与上海执行链开放前，此回退入口不会上传、报价或派单；带附件提交时，原文和附件保留在输入框。已提交或状态待核查的任务继续读取原任务回执，市场里的具名视频商品仍保留受审首帧准备和明确报价确认。存在有效任务合同本身不会开启尚未完成的正式快捷入口适配。

私有视频试用失败会在 Session 引用中保留有界的公共错误编号。广州通道/档位、首帧生成、原输入或记录容量不可用时显示明确的本地化说明；上游暂时读取失败仍可查询原任务，并提示等待核对。任何失败都不会自动启动另一份视频，只有明确的重出动作才创建新 UUID。

市场卡片通过 `uiWorkspace.registerSessionPreview` 提供只读的精确 Session 预览。已提交需求立即计入会话内容，即使可选账号历史尚未返回或浏览器持久化失败。冷预览只校验该 Session 的已保存记录，不创建 store、保留 Session、询价、派单或写入 Session 日志。无法读取或超出有界检查的历史保持不可读状态，阻止空白会话复用，不虚构标题或搜索文本。Workspace 负责标题和搜索长度上限。卸载该功能会移除预览注册并使晚到通知失效；可选 `usageOwner` 字段仍只表示历史归属，不授予权限。

千手 profile 的市场提供搜索、筛选和条目详情，真实内容来自 `listings` 与 `installed`。详情只展示目录声明的要求，区分内置能力登记和可下载插件包。**检查兼容性**调用只读的 Host `preflight`；通过前**添加内置能力**或**获取**保持关闭，添加时 Host 再次预检，防止设备状态变化。Host 检查目录来源、依赖、模型、发布者已声明的操作系统和应用进程架构、磁盘与内存；显卡和显存暂未实测。新安装的能力保持未发布，机主须在**我的能力**另行公开。

对已签名且固定版本的插件包，「已安装」仅证明 Host 已加载这个包。详情引导机主先试运行本机样例；对外接单仍需另行审核、机主授权和派单准入。内置「图片」预览继续不可安装，独立的已签名包型能力可先作为本机私有草稿安装。

**用千手创建插件**在专用预设可用时打开插件创作会话；仅打开会话不会保存草稿或发布插件。添加后，只有 Host 确认已保存条目的 ID、版本和插件包均与当前活动项相同，详情才显示**管理我的能力**，进入现有机主能力页。插件缺失、未激活或无法核验时不显示完成后的快捷入口。能力页可保存本机草稿或修改声明可见性；接单授权仍须机主单独决定。

机主明确要求创作助手试跑已经绑定的 ComfyUI API 图时，会话显示专用的私有样例卡。Host 提交前要求本次 GPU 操作的逐次审批。完成后，卡片仅从本机 Host 读取经机主身份、文件摘要核对的 PNG，显示尺寸与大小；失败或状态不明会用普通人能理解的话说明，不在卡片泄露图、模型文件名或样例提示词。本机样例既不是可安装插件，也不是可接单能力。该界面已有隔离假 Comfy 测试，仍需 Mac 和 Windows 真机验收。

`api` 模式把通过签名核对的广州发行资料放在独立的**已审核的发行资料**区。卡片显示名称、简介、操作数、适用系统；展开后可看操作、架构、权限、来源和原始包字节的核验范围。普通发行没有安装操作。对于精确的官方 CSV 种子，Host 另行核对签名身份和当前账号，页面才提供显示发行摘要的免费私有安装二次确认。Host 在写入私有回执前重新核对账号许可、完整包和样例；页面不会把这当成公开能力或接单许可。Host 入口、登录、信任公钥或有效发行缺失时，操作保持关闭并说明原因。原目录和发行资料分别计数；发行读取失败不影响原目录。内置模式不请求发行接口，并说明在线领取尚未配置。

账号身份变化或连接重置时，账号相关的投稿记录和预览组件立即卸载。投稿记录刷新失败时，先清掉上一个账号的记录再显示错误；Host 每次读取记录还会核对当前账号。

内置「文章」只保存本机能力声明，不安装插件包。目录摘要仍会校验，但空包的来源、依赖和模型三项显示**不适用**，资源项显示实测结果。添加后可点击**移除这条声明**并二次确认；页面等 Host 删除指定记录并重新读取已保存清单，才更新标记。机主可重新检查、添加。带插件包的条目仍在本机插件管理器卸载。本机保存的声明只有在 Host 当前回报同一个包及版本处于活动状态时才计入已安装；卸载后草稿仍留在页面上，但显示为未激活。旧 Host 若无法回答核验，则显示未知。这两种状态都不会进入「已安装」筛选或开放发布。

千手市场只保留一层主导航：**技能市场**、**我的技能**、**发布技能**。本机插件和接单能力通过独立管理页打开，并可返回技能市场；官方 profile 保留原插件布局。市场能力卡片通过按 Session 寻址的 `@` 入口回到当前主对话。商品卡片另建绑定商品编号、投稿、作者与版本的会话卡片，保留原输入草稿；不会把指定商品退化为同名 `@` 任务。选择前重新读取权威目录并核对身份。商品卡片在询价前核对公开目录，并要求上海报价回执回显精确商品身份；旧服务不回显时停止报价。提交前再次重读商品与任务合同，创建回执不回显则按未知提交状态核对，绝不自动重发。普通任务类型调用仍走原报价流程。选择卡片不会询价、购买或执行。默认只展示可调用的内联或多附件合同，另提供查看尚未开放能力的选项。能力和商品封面复用本地打包的静态图集。买断获取与设备安装验收保留独立操作。发布管理可以刷新真实审核回执、继续同一投稿的待完成源码归档、重试符合条件的审核样例，或打开对应技能；审核通过不会自动授权接单。新建技能、上传 SKILL.md 与通过 Git 链接安装保留原有确认流程。 同时支持文字与文件的合同在无附件时默认文字，已有附件时优先文件；显式切换保留两种草稿并使旧报价失效，已提交或状态未明的付费任务不能借切换重新派单。

发布管理只提供服务端为当前登录机主和精确记录版本允许的操作：撤回待审投稿、下架已审核技能、归档记录或恢复归档记录。确认框显示所选技能和影响。存在活动订单或待安装权益时，服务端阻止下架和归档。归档保留本机文件、购买权益及订单历史；恢复只让记录重新显示，不会批准、上架或启用接单。本机技能文件缺失时仍保留云端历史。失败或账号变化后的回复不会提前移除记录。

「新建 → 创建视频工作流」让机主选择已跑通的 ComfyUI API 格式 JSON 文件，填写名称，再把客户描述、可选参考图和可选生成帧数对应到流程输入。Host 会再次校验流程并保存为本机私有设计。此操作不会运行流程、发布技能、向客户收费或开启接单；真实本机试跑、打包核验和发布仍是独立步骤。Host 无法读取或保存设计时，页面会显示失败，不会宣称已完成。

技能广场下方的「社区插件」由机主主动发起公开仓库元数据搜索，结果明确标注未经千手审核；「检查安装包」将精确 `包名@版本` 带入现有 Host 安装审核框，不会因为搜索而安装。「新建 → 技能助手创作（技能 / 插件）」进入技能创作预设的空白对话，预填可编辑开头；该预设加载自己的 `skill-creator` 规范，先给出可审阅的 `SKILL.md` 草稿，写入本机需用户明确提出。同一个技能助手对话也可准备受限的本机插件候选包。「新建 → 通过 Git 链接安装」打开既有的 Host 插件 spec 对话框，并先检查包；该对话框也支持注册表 spec 与本地路径。「新建 → 上传 SKILL.md」读取单个本地 UTF-8 Markdown 文件（最多 256 KiB），由 Host 验证格式并展示名称、目标路径、SHA-256 摘要与调用方式，机主再次确认后才把核对过的原文写到本机用户技能目录；同名技能不会被覆盖。落盘回执与会话可调用状态分开。安装回执中断时，客户端调用 Host 的只读摘要核查；结果仍不明时保持待核验，不盲目重试写入。刷新会话技能后，页面用名称及来源路径核对本次文件；其他作用域的同名技能可能优先生效。这里不导入配套文件、压缩包或插件包。

市场和本机技能刷新时保留同一账号的展示卡片、筛选与滚动位置。读取中或失败后，缓存目录的选择、发布和作者启用操作禁用；本机接单资格与恢复的启用状态分别重新核实。已打开的任务表单保留输入，由 `catalogReady` 阻止新询价和派单确认，不中断已提交任务的进度读取。读取在 Host 工作前后核对当前账号；所有者变化或无法核实时清掉上一来源的展示，迟到回包不能覆盖当前账号数据。保留的元数据不会延长 CNY 报价时效，也不授予接单或执行权限。

普通 `SKILL.md` 的「请技能助手评估接单」只打开预填的评估对话。只有 Host 已登记任务合同、执行器与结果校验，并核对本机实际适配器文件后，技能卡片才提供真正的「发布接单技能」入口；助手的设计建议或对话可用状态不会自行登记执行器。

作者在同一次投稿中填写一次买断售价：0 元表示免费，最多两位小数，最高 100000 元。售价和本次源码版本一同锁定。平台审核同时上架已核验商品；客户端只根据真实商品回执显示已上架，不再要求二次申请。上海的通用任务执行价保持独立。旧投稿没有售价时，只显示审核状态，不宣称自动上架。实际接单仍须机主授权。

预检不过时页面按 Host 步骤显示失败原因和实测事实；被失败挡住的步骤仍标为未检查。系统兼容摘要区分符合、不符合、发布者未声明及尚未检查。恢复动作以 Host 返回为准：**修复**、**重新检查**、**取消**和**回滚**。检查不过时不会安装。

可下载目录包只有在 Host 报告 `applied` 后才写入市场能力登记。`restart-required` 显示为待重启核验，不写能力登记；取消、覆盖、失败或缺少结果也不登记，包本身状态以「本机插件」为准。读取失败是错误，不是空市场。页面不发送会话内容或账号凭据。草稿和私有能力留在本机；只有机主明确公开的能力才可能在节点下一次 hello 中到达上海，接单还受机主独立策略限制。内置目录没有价格、购买许可或评分数据，页面不虚构这些信息。

“我的能力”只读显示 Host 保存的机主策略，并提供入口前往独立的**接单**页管理总开关；默认关闭。接单页目前有已核验的 `text.transform` 服务逐项授权及总开关，不会因此让任意已安装插件取得接单资格。保存草稿或公开能力声明，都不等于上海已确认心跳或某项能力已可收费接单。通用插件逐项接单授权、价格和交付信息仍需已核验的本机服务/执行器映射及上海报价链，当前尚不可用。

此页另外展示经 Host 当次核验的 Mac 五秒绘图视频私有插件与精确执行器，卡片明确写“本机私有、可本机试用、尚未开放接单”，不提供公开按钮。其他包不会仅因为出现在插件管理器中就被推断成机主能力。

市场页独立读取可选的 Host `reviewedLocalStarters()` 本机目录，将固定 Mac 视频和离线 CSV 模板放在**本机插件试用入口**。页面按 Host 当次结果显示可由助手引导配置、已核验安装或不可用原因。引导按钮会把对应任务填入空的新会话输入框，由机主检查并发送；它不会直接安装、上架或开启接单。已核验的 Mac 视频包可进入现有本机插件管理；CSV 私有种子不是 Loader 包，页面改为说明在对话中使用。旧 Host 没有该接口或读取失败时显示明确提示，不虚构卡片。线上签名发行仍是独立区域，客户端使用内置目录时会说明尚未连接广州市场配置。

市场页还独立读取 `privatePluginActivations()`，按机主保存的名称和操作数展示任意自创的本机私有插件。Host 当次返回 `active-private` 或 `unavailable-private`；读取失败不会伪装成空列表。这些卡片不计入公开目录，不提供安装、购买或接单按钮。它们是本机清单，不表示插件已经上架或售出。

### 安装一个组合包

**添加插件**接受包名（可带版本）、Git 地址、压缩包或本地绝对路径；对话框说明包名就是 README 里 `dsh plugin add` 后面的那一段。输入框下方的**不知道该填什么？**展开一段引导，分别给出包名、Git 地址、本地目录和已下载 `.tgz` 的示例；**填入示例**把示例填进输入框。**安装**先让 Host 读出 spec 指向什么（`pluginManager.inspect`）：列表中已有的名字、注册表没有的名字、没有包的路径、没有组合包 patch 的包，或 pnpm 会拒绝的 spec，都以一句话回到输入框下方，spec 保留可继续编辑。通过检查的 spec 打开安装中界面，展示 Host 读到的包名、一句话简介和版本，pnpm 的命令与输出折叠在**查看安装详情**之后。安装完成后提供**立即启用**：启用新组合包、关闭对话框并把列表滚动到它；直接关闭则让它保持已安装但关闭。安装失败时用一行话说明原因——注册表或网络不可达、包不存在、磁盘已满、profile 不可写、pnpm 拦下了构建脚本——pnpm 输出在详情里，**重试**就在手边；Host 已经把 profile 文件放回原样。pnpm 拦下依赖的安装脚本时，失败界面列出等待允许的包，并以**允许这些脚本并重试**取代**重试**；Host 把授权写进 profile 的 `pnpm-workspace.yaml`（失败的运行保留 pnpm 写入的这个文件）再运行 pnpm，安装完成界面会说明允许了哪些脚本。安装成功不代表模块一定能够激活。

安装期间可点击**取消安装**，对话框显示**正在停止安装…**，直到 Host 确认。加载组合包的阶段不可取消。确认后对话框回到 spec 输入界面，可再次安装，并用 toast 说明安装已取消；manifest 与 lockfile 已恢复原样，已下载文件可能保留。安装进行中关闭对话框，同样会请求 Host 停止安装，Host 确认后对话框才关闭；Host 正在准备、停止或加载时不能关闭对话框。连接错误不代表取消成功：安装中界面会如此说明，可以再次尝试取消。

### 切换一个组合包

组合包页面在标题下方显示完整包名，也就是在别处安装它所需的 spec。组合包开关改变其层选择。启用了 HMR 的 profile 在操作完成前重组；没有 HMR 的 profile，以及被更高层覆盖的组合包，会以 toast 说明。Host 读不了的组合包带异常标签，其页面给出原因，且不能打开；提供管理组件的组合包保持锁定。Host 以错误码作答，由页面字典措辞；pnpm 与 Loader 自己的诊断原样显示。页面从卡片与数量中排除内置 profile 组合包，即使 profile 将它们列为依赖或 Host 报告了异常。Host 清单仍保留完整数据；设置中「插件」分区的「插件列表」标签页负责查看它们的插件。

### 加载检查与注册表更新

**加载检查**向 Host 请求带时间的组合包选择和已声明行观察结果。它不调用业务 API、不检查浏览器半侧，也不代表安全认证。请求失败不会保留成功结果；本机变更会使先前检查失效。卡片摘要仍以实时组件清单为准。

**更新版本**接受同名注册表包的版本或标签，并将预检目标固定为精确版本。检查后显示新旧版本与保留的启用状态，再点击**确认更新**才开始替换。Host 在事务锁内重新核对检查结果。取消、日志和脚本批准共用安装协议；批准脚本只重试已检查的替换。检查过期或当前包已变化时拒绝更新，普通重试要求重新检查并确认。成功后保留启用状态，并要求重启应用；更新完成不提供**立即启用**。安装的 Host 代码以宿主用户权限运行，不受会话工作区沙箱约束。

### 切换组合包里的一行

组合包页面上行的开关调用 `pluginManager.setPluginEnabled`，往 profile 的 `cordis.patch.yml` 写入该行的 `disabled` 覆盖。启用了 HMR 的 profile 的树随即重组，该行的宿主半区卸下或挂上，组合包其余部分照常运行，页面无需重载即跟随客户端模块图。行按 Host 运行它们的 fiber 阶段显示状态。开关只出现在已打开的组合包上；没有存活条目的行，以及 Host 不通过 profile patch 寻址的行，带着 Host 的原因锁定。超过十行的列表带一个按行 id 筛选的输入框。

### 配置页

自带配置的插件把配置渲染在本页而不是设置里，通过本页声明的三个 slot：`plugins.item`（list）用于配置页，按其 `label` 列在功能设置分组里；`plugins.bundle.config`（以组合包的包名为键）用于组合包自己的配置，显示在组合包页面的描述与行之间；`plugins.row.config`（以 `<包名>#<行 id>` 为键）用于某一行的配置，这一行由此多出一个**配置**控件，打开该行自己的页面。页面通过 owner props 向每个条目索取两种视图：`view: 'summary'` 是标题下的一句话简介，`view: 'page'` 是带自己保存控件的表单。只有保存才写入：页面负责画标题、图标与面包屑，条目的表单在离开页面时丢弃暂存的修改。安装随附的四个宿主平面配置页——shell 执行器、agent loop、subagent 模型选择、DeepSeek 搜索提供方——来自 [ui-settings-plugins](../ui-settings-plugins/README.zh.md)，在 Host 服务其命名空间期间注册。组合包的浏览器半侧用同样的方式注册：

```tsx ignore-check
ctx.slots.inject('plugins.row.config', () => ctx.slots.register({
  name: 'plugins.row.config',
  key: '@acme/dsh-sidebar#sidebar',
  locale: 'acmeSidebar',
}, ({ t, view }) => view === 'summary' ? t('summary') : <SidebarForm t={t} />))
```

组合包的 patch 必须以该 id 声明这一行；注册只在组合包开启期间存在，因此关闭的组合包不显示配置控件。

### 图像与视频试用

本机 Host 显式开启研究出图试用后，在调用模式发送 `@出图` 和画面描述，即经广州提交一次不计费八步任务，无参数表单和二次开始按钮。描述原样保留，默认横屏 2048 × 1152；明确写“竖屏”使用 1152 × 2048，写“方图”使用 1024 × 1024。方向词冲突或携带未支持的附件时，保留对话输入且不提交。首次 POST 前必须从所属 Session 的存储读回已保存请求，持久化失败不发单。重新打开或查询已存请求只读取原任务；旧草稿提示在对话重新发送。设备忙、缺少凭据等 Host 明确未受理错误提示用户重新发送；未知故障和编号冲突保留原任务引用，只查询而不重发。状态、图片和下载均走已认证的同源 Host 接口。调用模式下试用未开启或状态接口不可读时，入口说明免费出图暂不可用，不提交试用或正式市场任务，原输入保留。内联活动显示不定进度条与本地小卡工作动画，按 Host 实际回执区分等待节点生成和媒体回传，并显示自受理时刻起的已用时间；旧回执只标注本次查看的等待时间。不显示推测百分比或预计完成时间，浏览器读图与生成分开提示，减少动态效果偏好会关闭动画。研究结果不创建市场商品、上海报价或结算记录。

点击生成图片可放大查看已校验的 PNG 原图，在适应窗口与可滚动的 100% 原尺寸之间切换；按 Esc、点击遮罩或关闭后焦点回到图片。结果和放大层均可下载、复制图片字节，也提供右键菜单；剪贴板失败会明确提示。重新出图需要对已完成研究图单独点击，保留原图并用同样描述与尺寸创建独立请求；重新加载只查询已存请求，不会重发。更清晰与高清分别在明确确认后使用 12、20 步采样，保留原提示词、输出尺寸和原图，创建新的不计费试用任务；画面可能变化，生成耗时增加。按钮需当前 Host 上报支持，旧 Host 保持禁用。重新出图沿用所选图片的采样档位。附件复用及正式报价仍未开放。

Host 显式开启视频试用后，调用模式的 `@出视频` 接受原始描述，以及可选的一张 PNG/JPEG 首帧（最多 16 MiB）；未附图时，Host 先通过共享图片试用生成首帧，再交 H3。固定研究参数为请求五秒、横屏 1344 × 768、四步；不支持的时长、方向、画质、尾帧及附件要求会保留输入且不发单。独立 Session 存储先持久化请求编号与首帧来源和摘要再 POST，不保存 base64。提交结果未知时保留输入和原请求，只允许 GET 核对。时间线与工作区预览共同保留纯媒体会话。内联阶段和已用时间来自 Host 回执，只有上游提供真实进度时才显示百分比。同源 MP4 限制为 16 MiB，按回执校验大小与 SHA-256 后播放并下载原片。明确点击重新出片才使用新编号和已完成父任务编号，由 Host 复用原首帧与原设置；旧视频保留。更清晰和高清在真实报价合同开放前保持禁用。此通道不创建正式市场订单、上海派单或扣费。

仅有图片的会话通过精确的已存请求注册只读 Workspace 预览，切走或重启后仍在侧栏保留，也不会被当成空会话复用。预览不会发起任务、持有 Host 会话、修改空会话标记或伪造用户消息；存储无法读取时，保守保留会话已有内容的状态。

查询原任务操作在下载被拒绝后，只对本次点击的具体请求和 Session 复核一次交付。首次读取即消耗该操作，重新渲染或切换任务不能继承它；后续轮询正常读取同一个作业。查询和恢复会话均不提交生成。

**运行时不变式：** 不发布伴生检查。本包只拥有一个基于 Host 事实的侧栏面板。

调用卡片展示服务端实际进度、执行阶段，以及从服务端创建时刻起的等待时间。执行方没有进度或仅返回零时使用不定进度条，等待时长不推算百分比。终态停止动画并以普通语言说明完成情况。进度读取失败会通过只读请求重连，结果读取失败单独重试。订单编号放在折叠的排查信息内。

发布管理分别显示技能审批、归档确认、市场上架和设备接单状态。技能已审核、归档已确认且商品记录读取成功并确认无商品时，作者可以明确填写一次性售价。输入初始为空，明确输入 0 才表示免费，执行价不会填入售价；投稿已有的显式售价保持锁定。只有作者点击提交才申请商品审核，不会因此上架、批准、购买或启用接单。加载中、记录过期、商品记录不可用或已有商品标记时禁止重复提交。失败后保留输入，账户变化或服务卸载后忽略迟到回复。

「我的技能」先显示当前所有者的本机文件清单，再后台核对资格与设备接单状态。本机适配资格独立更新；等待或失败不表示已审核或已开启接单。`qianshou_skill_complete` 与成功的 `qianshou_try_local_skill` 结果依据持久 Host 元数据展示作者操作卡。本机试用读取精确源码的输入声明，展示普通字段；开发者 JSON 收在高级选项中。缺表单引导作者通过技能助手补齐，尚无本机文件试用通道的文件合同明确不可用。Host 拒绝读表单后源码发生变化的试用，继续验证真实样例与输入。失败保留输入；发布打开精确来源与名称的「我的技能」，沿用现有审核、定价及提交按钮。渲染和跳转不发布、不购买、不启用技能。 待审核状态只在「我的技能」可见且非忙碌时每 15 秒真实读取平台；成功 GET 写入并展示 `reviewSyncedAt`，失败保留过期状态，旧审核通过不能证明已变更的当前源码仍已上架。

异步投稿验证期间，发布管理在可见页面定时串行读取作者的投稿状态；已结束验证或页面隐藏时停止轮询。回执尚未生成与无效回执分别显示，机器回执齐备不代表管理员已批准。读取不会提交、批准或重新签发回执。执行报价明确区分服务端价目未配置与无效；两者均不提供派单确认，也不会写入价格。

本机“我的技能”卡片只为 Host 认定的用户文件提供明确、可恢复的移除入口。确认区显示所选技能，并说明云端投稿、购买权益及接单安装包仍保留。核验归档回执后立即移除该卡并刷新本机与会话清单，多次移除合成一条可关闭的简短提示。「回收站」打开时读取 Host 的真实归档清单，按设备语言和时区显示名称与日期，技术路径收在「查看详情」。同一路径再次归档时，新核验回执也会更新单条提示。恢复只接受已核对的选中归档，由用户明确点击，并在完整匹配的成功回执后刷新清单，不发布或新增接单授权。冲突或失败保留备份，账号变化丢弃旧恢复列表；内容已变更、受管安装包及当前选定的节点执行目录仍受保护。

已购买的接单商品使用当前账户身份与独立身份版本，与公开目录分别管理。账户变化立即清除私有权益、卖家标记和待处理动作显示；上一账户的读取、购买和激活迟到回复不能进入另一账户。购买前及每次回复后重新核对身份。身份变化与连接恢复事件仅触发读取，不自动重买或重试激活；同账户重连保留不确定购买的幂等键，换账户清除这些键。退出登录不读取私有权益，身份读取失败后须明确刷新成功才能购买。十项隔离控制器用例覆盖迟到读取与动作回执、退出、恢复及幂等键隔离，不修改真实账户。

千手「我的技能」卡片按网格行顶部排列，不再拉伸到同排最长回执的高度。「在对话中使用」和「立即试用」保持直接操作，投稿和可恢复的本机移除仍走原核验流程，收在「管理」内。调用指令、投稿编号和长审核回执归入「查看详情」。状态待核对、无效样例、源码迁移要求和生命周期阻断仍直接可见，审核未通过的详情默认展开。发布管理将最后同步时间放在页头，每项实际执行价和商品买断价只显示一次，分别表达平台审核、商品上架和已保存的接单授权；简短的授权标签不表示这台电脑当前正在接单。

旧版 JSON 任务先只读请求与商品、任务、版本和产物摘要精确绑定的便捷输入展示。只有经 Host 验签与摘要核对的扁平样例，其中仅一项文字变化、其余为固定基础值时，才生成普通输入控件。账号、目录或身份变化后丢弃迟到结果。客户端合并固定值时仍遵守原输入长度和字节限制，报价与付费确认保持原有流程。无法整理时显示收起的高级输入，不猜业务字段。视频抽帧在上传前显示执行器支持的视频格式，拒绝图片，并提醒当前多文件表单需先解压 ZIP 再选视频。既有不适配的附件引用仍可移除，不能取得报价。

同账号刷新本机清单时，已打开的发布草稿在读取当前资格期间保持可见；只有所选源与新资格匹配后才能提交。账号变化、文件消失或内容变化、已确认失去资格会清除草稿。原 Host 投稿操作仍重新检查价格和运行包摘要。

原生 H3 作者启用使用独立设备证明回执，不虚构商品或安装编号。本机与发布页面仅在当前 Host 声明和投稿元数据都明确标识 `native-h3`、本机源仍存在、批准与不可变归档证据均为当前状态时，显示原有启用动作。原生成功必须核对所选来源、实际设备、配置摘要、已验证设备证明及已保存的节点授权。普通商品启用仍要求真实商品编号与本机安装回执。这些确认不表示机器此刻在线或已满足接单空闲条件。

正式图像/视频候选沿用原调用对话、`@出图`/`@出视频` 和附件，保留 CEO、技能助手、调用三入口。从未改写的原消息读取确切画质、方向和视频秒数，只匹配唯一已启用的官方档位与版本；缺少或冲突时保留输入框内容。指定步数、帧率和尺寸也须与官方档位一致。正式目录就绪时优先使用正式协议，显式启用的不计费试用保持独立。目录读取失败不会悄悄发起试用或付费任务；官方档位不可用时不虚构价格。

原对话内的官方报价卡显示服务端原始人民币字符串，须用户当次点击“确认报价并派单”。持久 UUID 引用和已显示报价不含附件字节、报价 token、viewer grant 或认证请求头。Host 只接受同账号和原 Session 的确认。未知任务冷恢复只查原 requestId；未知 POST 结果不能授权重新提交。Host 明确拒绝且尚未提交时可由用户重新报价；重启前未用的报价须取得新 Host 票据。挂载卡片或刷新账号元数据都不会确认付款。

PNG/JPEG 附件由 Host 接广州账号范围的公开 ticket/upload/status 链路，视频按附件顺序标明首帧、尾帧，图像使用 reference。附件恢复只查原资产 UUID，不重传字节；全部附件取得一致登记回执后才能报价。已结算结果校验 Host 响应字节长度和 SHA-256 后创建本地 Blob 预览，并下载原字节。切换任务或卸载会中止旧交付并撤销预览 URL。未知进度保持不定进度条，显示服务端耗时；轮询使用 Host 经校验的间隔。交付失败只重新读取原结果，不重新生成或扣费。

研究视频断线用普通服务未连接提示，并说明本次未开始、未计费；技术错误码放入折叠“诊断详情”。这些源码及 HTTP/浏览器夹具属于候选证据，不是生产计费、正式档位设备资格、Windows 原生播放或发布证据。

已有本机技能的添加操作沿用 Host 先预检后安装流程，不跳过校验。当前会话技能保留直接带入对话的操作。真实已审核普通目录使用独立服务端记录，仍不可购买或安装。云端图像／视频合同与旧维护控件收在可选详情里。发布页说明广州工作人员人工拉取并测试后再上架；上架与售价仍依据真实服务端记录。设计方案或本机对话技能不会自动成为受审市场商品。

### 普通技能投稿与已审核目录

真实普通技能目录和投稿面板使用框架注入的 `ordinarySkills` observable 及普通读取、编辑、提交回调。作者选择本机已有技能，编辑名称和简介，明确填写售价后，当次点击“明确提交人工审核”。读取和挂载都不会投稿。结果不明的原 UUID 只允许“查询原投稿”；账号变化清除当前草稿，丢弃迟到响应。卡片显示原售价、技能包 SHA-256、人工测试回执及服务端决定的官方／用户作者分类。普通接口独立于旧 adapter 列表；消费账本接通前明确不可购买、不可安装，不显示对应操作按钮。

正式附件输入限制 16 MiB、4096 像素；正式结果交付另有 64 MiB 上限。`formalMediaGatewayOrigin` 为空时仍可读取官方档位目录，报价以 HTTP 503 `COMPUTE_MEDIA_DELIVERY_UNAVAILABLE` 拒绝，确认以 HTTP 409 `COMPUTE_MEDIA_CONFIRM_NOT_STARTED` 拒绝，均先于 estimate、账本或 workload 提交。源码和定向夹具不证明生产付款或 Windows 原生验收。

### 当前图像／视频试运行界面

Host 明确启用同账号研究调度后，新的横屏八步调用沿用原对话卡片，显示实际观测的排队、原任务确认、生成和媒体回传阶段，不增加选电脑或再次提交的操作。原请求 UUID 始终绑定已保存的 Host 通道，配置改变或冷启动也不切换；本机原图文件缺失时只恢复已完成任务的原图下载。独立启用的方图、竖屏和 12／20 步试用仍走原通道，不降低用户选择的规格来迁就节点。固定研究队列保持免费，正式价格、视频调度和跨账号供给独立接入。

技能中心只显示“技能市场”和“我的技能”；接单左导航、发布技能、新建、接单商品和执行适配器控件在此阶段隐藏。旧服务和历史数据保留，旧发布链接仅定位原本机技能，不打开投稿表单。算力贡献通过“算力共享”启用。

市场包含本版本随客户端分发的两个官方纯说明技能“图像创作”和“视频创作”。点击安装将这些固定 SKILL.md 字节送入既有 Host inspect/install/verify 流程，原 inspection 仅写一次；结果不明只核对原写入，不重复安装。同名不同字节不会标为官方已安装。成功后刷新本机清单和当前会话，使用按钮仍以真实会话发现为准。安装说明技能不表示模型、视频 API 或共享授权已可用。

开发者入口跳转现有讨论区。当前云效检查点的论坛仅支持文字帖子，可贴技能正文；技能文件上传尚在独立候选中，未合入该检查点。服务器普通收费目录仍独立，未接通购买或安装的条目不伪造操作。前文旧投稿与接单模块是保留的内部实现，不是本阶段可见入口。

<a id="understand-the-implementation"></a>
## 理解实现

投稿归档中断时，同一账号读取同一技能、同一待完成投稿，会保留签名或上传失败原因。归档确认、新投稿或账号变化会清除原因；迟到的继续提交回复不能重新写入已变更的记录。「我的技能」与「发布管理」共用本地化错误提示，未知错误不展示原始 URL 或凭据。

插件管理依据 profile 的依赖记录：已安装组合包可启停、可移除，随安装提供的组合包保持锁定。这一区分不决定启动失败策略。

<details>
<summary>实现细节——点击展开</summary>

### 注册

浏览器插件通过 `ctx.slots.inject()` 注册 `plugins` 侧栏入口与它的 `main` 面板，使两者跟随 slot 延迟声明、本地化变化与销毁。页面为全局页面，不属于任何 Session。显示文本来自包元信息与页面字典。

### store

`PluginManagerController` 拥有组合包视图、忙碌键、提示、安装进度和卸载确认。每次读取先问清单 Host 是否管理着 profile，再把 `listBundles` 与 `listPlugins` 合成每个组合包一份视图，其行携带存活条目的启停状态与 fiber 阶段。它合并重叠读取，在操作后、收到 `plugin-manager/changed` 时以及重连后刷新，并在销毁后忽略晚到结果。安装输出按 job id 分组。安装对话框沿 `idle → checking → starting → running → done | failed`（更新在 `starting` 前插入 `review`） 推进，`cancelling` 与 `applying` 按 Host 的报告呈现。检查在一个 `AbortController` 下运行，返回编辑或关闭会中止它并丢弃其结果；运行只能通过 `pluginManager.cancelInstall` 停止，对话框等待其答复。Host 无法应用的变更、要等重启的变更、被更高层覆盖的变更，都是会自行消失的 toast。

### 配置 slot

页面的 `main` 注册把 `plugins.item`、`plugins.bundle.config` 与 `plugins.row.config` 声明为子 slot，因此它们与页面同生，注册方的 `ctx.slots.inject` 会等到它们出现。`configLedgerSource` 把三份账本投影成一个可观察对象——按账本顺序排列、标签按当前语言解析的配置条目，以及组合包与行的键——在账本或语言变化前保持缓存；页面把它作为 `useConfigLedger` 绑在 store 旁边，自身从不点名任何可配置插件。打开的是哪一页是页面本地状态：卡片、某个组合包、某个配置页，或组合包的某一行。注册与做出它的浏览器半侧同生共死。`dsh-client-modules` 只把一个包的浏览器半侧挂在说明符恰为包名的那一行 Loader 行上，所以组合包为自己或任一行注册的页面，都会在那一行被关闭时一起消失；需要在其他行关闭时仍保留页面的子插件，应作为独立的包发布。

## 已知限制与延期工作

<a id="known-limitations-and-deferred-work"></a>


这些限制界定了管理视图的范围；它们是当前包的约束。

- **只管理组合包**——没有组合包 patch 的依赖在安装前就被拒绝；profile 里已有的这类依赖不上页面，除非 profile 选中了它；加载普通插件模块仍是文件操作。
- **行只显示阶段，不显示原因**——失败的行只显示为失败，没有 Host 的错误文本；Host 日志里有。
- **一次只能安装一个**——对话框一次运行一个 pnpm 命令；第二个 spec 要等前一个完成。
- **没有版本历史选择器**——注册表更新需要输入版本或标签，并确认解析出的精确版本；不提供本地路径、Git 或压缩包替换。
