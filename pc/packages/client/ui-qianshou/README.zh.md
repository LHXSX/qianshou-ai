# @deepseek-ai/dsh-client-ui-qianshou

[English](README.md) | 中文

## 概述

`qianshou` 客户端构建使用用户提供的金色双手托棋徽章、本地化名称与主题强调色；同一徽章用于会话首页、账号欢迎页和“关于千手”。云端账号链接由账号菜单提供，不再单独占用侧边栏底部操作位。其他构建不产生注册项。它也提供停靠的“子代理任务”分栏，从会话目录订阅真实任务，并在右侧打开既有子代理会话。

## 使用本包

调用模式的输入栏只提供出图、出视频两个入口。选择时把对应引用加入原草稿并返回对话，不提交任务或请求付款；需求直接在对话中描述。CEO 与技能创作沿用原有本机技能、插件和市场展板。具体可用性与实际执行由媒体入口和 Host 决定。侧栏“日常／工作”仍只控制导航，与三个对话模式独立。

能力卡片使用一张随包静态分类封面图集；图片仅作装饰，名称、来源徽标、价格和按钮仍为真实可读控件。封面不播放媒体、不读取发布者远程图片地址。市场后台刷新时，已有可调用卡片可以发起选择：选择器先固定已展示的执行合同与商品发布、机主、版本、价格身份，再刷新权威目录，仅在身份仍一致时写入引用。核对期间显示状态；变化、不可用或读取失败都保留草稿并明确拒绝。选择不会延长报价有效期或授权付费。

Web bundle 加载本包。构建使用 `DSH_CLIENT_BUILD_PROFILE=qianshou` 和公开标题 `千手 PC · 开发版`。贡献等待父插槽声明，插件或父声明卸载后移除。浅色、深色和跟随系统继续由主题服务控制。

展开的侧栏提供「日常 / 工作」切换。日常打开普通对话并隐藏工作专属导航；工作恢复先前打开的工作面板。这是在现有 PC profile 内切换导航，两种模式尚未拥有独立会话目录。输入栏「技能与插件」打开较大展板，提供常驻搜索、内容大类、依据元数据划分的二级细类和能力卡片。它通过 `remote.skills.list` 读取当前会话技能，并读取已启用本机插件和经过审核的市场任务目录；来源徽标区分官方能力、用户市场与本机技能。选择本机技能或插件请求时保留原草稿的所有字符。市场选择把原会话与精确任务类型交给 `qianshouMarketSelection.refreshAndSelect`，市场所有者先刷新既有 @ 输入路径使用的同一目录，再写入引用；拒绝选择时保留草稿。共享选择器暂缺或卸载时，本机入口仍保留，市场目录明确显示不可用。选择留在当前对话，不报价、不执行、不购买、不安装，也不跳市场。按次执行报价与商品真实买断售价分别标注；零价商品仅表示免费获取、调用另计，本机条目说明在本机运行，外部服务费用按技能说明；这不表示免费。打开优先使用当前会话的技能缓存，显式刷新才重新读取；Host 发现技能文件变化后刷新已挂载会话，预设变化或连接重置会使技能缓存失效。

左侧「算力共享」下方的「讨论区」通过同源 `/api/qianshou/community/*` 读取广州论坛。现有 Connection 浏览器会话先校验本机页面请求，Host 再取当前千手账号访问令牌发往广州；渲染层不持有令牌。页面可按服务端分类浏览、搜索、发帖、回复、由作者标记解决和举报，活动公告显示服务端 `official` 标记。发帖时选择技能或商品，按名称或用途搜索 Host 的真实市场目录，再选择卡片；商品卡片显示实际售价和版本。选择保留帖子草稿，只填写原有关联，获取和购买仍由市场处理。关联任务打开当前目录精确合同，旧本机技能链接仍按原有方式搜索。未登录、广州不可达和空列表分别显示，不把静态示例当作真实帖子。上游默认 `https://admin.qianshousuanli.com`，运营隔离环境可用 `QIANSHOU_FORUM_API_BASE` 配置 HTTPS origin 或本机回环 HTTP origin；Host 仅代理七条固定 JSON 路由，限制请求和响应体大小。

帖子详情从完整的已审核市场目录解析关联中文名称，已有帖子也适用。商品 ID 仅作为内部跳转键；无法解析时显示可读的暂不可用提示。发帖区的类型选择保持紧凑，搜索控件对齐，结果列表独立滚动。

结果图片、动图和视频可由本机同源 `GET /api/qianshou/result-media?task_id=…&asset_id=<64 位 SHA-256>&type=<媒体扩展名>` 读取。Connection 先鉴权页面请求；Host 使用当前千手账号令牌优先向上海 `GET /api/v8/workloads/{task_id}/media-view-grant?asset_id=…` 取得短期查看授权，仅在明确的 404 时回退到开发者任务授权接口，再直接向广州 `GET /media/result` 取字节。上海只签控制信息，不中转媒体；网页拿不到账号令牌或查看授权。广州 origin 必须显式配置 `QIANSHOU_RESULT_MEDIA_BASE`（HTTPS 或本机回环 HTTP），未配置返回 503；上海默认 `https://qianshousuanli.com`，隔离环境可用 `QIANSHOU_RESULT_MEDIA_CORE_BASE` 指定。Host 要求一个受支持的媒体扩展名，并核对广州 Content-Type 与扩展名一致；最多 64 MiB，校验单段 Range、响应长度和 Content-Range，拒绝上游重定向、HTML 与压缩响应。视频链接还会先核对上海当前账号与任务详情；受审任务只能读取匹配的 MP4 结果，普通 WebM/MOV 任务仍可读取。审核详情缺失或损坏时会在申请查看授权前拒绝。该代理不表示上海发放授权或广州服务已部署。

有界普通文件使用单独、默认关闭的 Host 路由 `GET /api/qianshou/result-file?task_id=…&asset_id=<64 位 SHA-256>`。完成独立文件用途登记后，配置 `QIANSHOU_RESULT_FILE_ENABLED=1`、确切的上海以外文件服务 origin `QIANSHOU_RESULT_FILE_BASE` 与控制面 origin `QIANSHOU_RESULT_FILE_CORE_BASE`。当前账号取得有效期 60 秒、签名绑定所有者的下载授权；广州通过专用 `file-result` 只读身份读取 COS 已锁定的确切版本。Host 校验授权的完整 28 个元数据字段、有界长度与实际 SHA-256，最多以 `application/octet-stream` 和 `Content-Disposition: attachment` 返回 16 KiB。账号变化、取消、超时、多余查询字段、公开 URL、Range 请求及不安全上游头均被拒绝；存储地址和私有授权不会进入渲染器。此路径不提供 HTML 预览或媒体语义。候选传输实现未增加对话下载按钮，也不能证明文件执行、设备准入或交付已经部署。

任务入口跨分栏定位已经打开的任务页。新委派或子代理再次运行时自动展开；关闭后不会被同一未变化的任务反复打开。运行状态与会话模式分开展示，布局为任务分栏预留空间。已保存的访问凭据尚未过期时，Host 打开窗口里的专员接单。接单页负责设备接单总开关，并读取 Host 的本机技能与插件安装清单；分类仅依据明确元数据，尚无平台任务适配的已安装项目仍可见但不能授权。对 `word_count`，机主先选择通过校验的本机执行器，再单独授权 `node` 服务。选择与授权都不保证实时准入、订单或收入，页面还会显示当前节点准入原因。字符数或字节数插件不符合词频任务要求。本包不启动内建数词进程、不刷新账号，也不改变模型路由。

接单页重新读取 Host 数据时保留当前来源的卡片、分类、展开详情与滚动位置。只有首次尚无数据时显示整块加载提示；后续显示小更新或失败提示，写入期间标记受影响的项目。缓存的资格不能授权接单：选择执行器、保存授权和作者启用都需要成功的当前读取与 Host 实时校验。历史回执及对话能力目录在刷新失败后也保留展示数据，过期目录的选择按钮禁用。数据来源、worker 或机主身份改变时清除上一来源的展示，并要求重新读取供给状态。展示缓存不会延长 CNY 报价时效，也不能替代执行授权。

普通请求连同完整历史进入对话。输入框旁不再提供只看单句的路线预览。智能体可通过只读工具查看本机已注册能力和共享能力，并在原对话提出可核对的方案。执行、插件安装、付费订单和公开接单仍有独立的 Host 与机主确认闸门。

智能体保存分布式算力草稿后，可回放的工具结果会呈现为对话卡。卡片重新读取本机权威草稿，让机主同意或取消方案，再请求上海实时报价。界面展示服务端建议的确切提交预算、有效期、计价依据和完整文字输入；只有机主另点确认预算才提交，实际扣费或退款以后续任务账本为准。过期或余额不足的报价不能提交；结果不明的提交不会自动重试。普通聊天和草稿首次出现时都不会下单。

任务列表包含只读的子任务文件变化区域，显示真实来源子会话、轮次、工作目录、共享编辑提示与副本可用性。可用记录在对话旁打开现有差异面板；缺失或过期证据不会显示可打开的差异链接。侧栏已展开时，后台任务活动保留当前详情或预览焦点；用户手动点击任务入口仍会跨面板聚焦已有任务标签页。

左侧原「使用帮助」已改为「算力共享」，保留已保存的面板身份。仅提供图像和视频两种模式，主区显示通用本机模型库存、已核对的 API 和广州连接。已授权但尚未就绪时提供「继续启动」并发送准备指令；本机 API 已获广州确认时提供「暂停共享」。首次启用仍需明确确认所选范围。本机 Host 负责硬件检测、已有模型与服务发现、受审方案匹配、缺少文件的下载、安装、回环 API 和主动连接广州；渲染器通过 `/api/qianshou/node/sharing/*` 只读取去除私有配置的状态。每项分别显示通用本机模型库存、已核对的运行服务和共享资格；库存不等于该模式的资格，缺少受审方案不表示本机没有模型，也不授权重新下载已有文件。可复用及已采用标签必须来自 Host 已核验的文件和运行实例。页面在主栏内自行承担受高度约束的纵向滚动，小窗口仍能浏览完整内容；较矮的桌面窗口另压缩间距。七步安装过程收在展开详情中。调用次数与 CNY 收益来自唯一结算回执及真实账本，数据不可用时保持未知。换号清除旧回执；指令结果未知时只通过 GET 核对，不重发 POST。官方模型发行与真实设备资格仍是独立部署前提。

启用与继续仅在所选模式没有当前设备绑定的闲时授权时打开短确认，说明主动连接广州、仅空闲时执行、可暂停、已有资源优先核验复用，以及订单与收益不保证。首次确认或复用同一当前授权的显式准备点击会发送 `consent: { version: 'qianshou.media-sharing-consent.v1', connection: true, execution: 'idle_only' }`，同时绑定原模式、请求 UUID 和 Host `scopeId`。独立媒体授权不改变旧工具总开关或逐项授权。暂停停止接新任务；另有撤销本项授权入口。换号清除确认窗口与未知操作，旧窗口回调不能确认新范围。控制器在写入前消耗一次性确认；POST 结果未知时保留原 UUID，只查询 `status?request_id=UUID`，确切 `not_found` 后可再次明确操作；缺少当前设备绑定授权时仍需确认。旧 desired 不能升级权限；未提供范围的旧 Host 可读检测结果但不能授予共享。连接许可、闲时执行许可、受审模型与设备资格、实际共享分别展示。Mac 研究 API 运行或本机模型库存不能证明正式共享资格。缺受审方案、资源观察未知和执行否决均保留为具体阻断。

已授权设备同时缺少受审方案时，卡片优先说明方案缺失，不再只提示等待空闲；空闲状态本身不表示已经可以接单。已有当前设备绑定的闲时授权、处于未启用、阻断或失败状态时，主按钮显示「继续启动」，发送当前范围的启用指令，重新核对本机资源并准备连接。控制器只复用所选模式的当前授权；已撤销、不完整或未绑定的权限仍需确认。本机 API 新近获广州确认时提供「暂停共享」。准备进度直接显示在主卡片，只有正在发送指令的模式显示「正在处理」。写入结果未知时保留原 UUID，不发送新的准备 POST。本机 API 当前可用且已授权连接、心跳已被接受时，页面显示不计费试运行连接就绪，即使正式收费资源资格尚未核验；这不表示广州已确认 API 或生成已经成功。受审方案、档位、设备资格与收费阻断独立放在折叠说明中。本机服务缺失仍显示不可用，无 API 时的受控适配自动准备不冒充已经实现。

每项可选的 API 观察只投影固定适配器、模型与工作流友好名称、登记状态及最近真实元数据往返回执。缺字段保持未知。广州确认要求当前范围授权、已接受的通道与心跳，以及 120 秒内登记成功且通过的回执；本机健康不能单独证明广州确认。读取失败或换号撤回旧确认。未知指纹保持未知，API 元数据不发布收费能力，也不产生生成任务。

共享控制器在 PC 启动时及每五秒读取状态。状态读取先及时返回当前账号范围内的观察，并触发后台发现与默认域名的广州公开探测，不排在模型启动、GPU 执行或慢元数据请求后面。网关可达、已认证的设备连接授权、任务通道与当前 epoch 的已接受心跳分别显示；匿名用户也能查看网关可达性。本机服务就绪不能单独显示正在接单；共享中还要求已核验并采用资源、当前认证授权、已连接通道和已接受心跳。渲染器只接收有限状态和时间，不接收私有地址、模型路径或凭据。本机读取设有十秒期限，包含不响应取消的 IPC；失败显示「检测未完成」与「重新检测」，丢弃晚到回复，并撤销旧的已连接及本机服务提示，保留已有模式统计；换号清除前一个账号并丢弃晚到响应。提示仅用有界的 HTTP 状态与错误码区分 Host 缺失、状态超时、登录未就绪、Host 暂不可用或响应不兼容，不显示服务端原文及地址。旧 Host 未返回本机检测或连接字段时保持未知。

## 模型体验

### 委派消息

#### 模型看到什么

`subagent` 运行时仍是任务状态的来源。“派发设置”可选择自动、一次性或持续协作方式，以及专业或自定义角色。提交通过 CEO 会话的正常队列发送一条可见用户消息，并保留主输入框草稿。记录中的请求包含所选生命周期、角色、目标和验收要求，使用普通模型调用及 token 计费。请求已入队不等于实际派发或完成；任务卡始终读取 Host 的实际 descriptor。本包不增加新工具或持久化格式。

#### Token 影响

提交委派会增加普通可见用户消息及其正常 token 用量；展示任务卡不会发起模型请求。

#### KV Cache 影响

委派通过普通 Session 输入追加，不重写历史消息，也不引入另一套提示词前缀。

## 已知限制与后续工作

<a id="known-limitations-and-deferred-work"></a>

千手 profile 通过现有主题覆盖层统一浅色与深色的背景、面板、侧栏、文字和细框线，字体与主题偏好仍由用户设置控制。覆盖层卸载时移除，官方 profile 不注册。分类封面是无业务依赖的共享静态 `ui-primitives/SkillCover`，市场与对话展板共用同一份图集及映射；名称、价格、审核和可用状态始终使用真实可访问DOM，不绘入装饰图片。

- 云端链接打开既有网站，不会将浏览器登录自动带入本地 profile。任务窗口不将“暂未运行”判为验收完成；专业角色来自 CEO 的真实委派描述。设备配对、能力报价和账号登录分别实施。桌面安装身份与更新需要独立发行配置。注册项由同一插件拥有，并通过生命周期及组装 UI 检查验证移除，因此不发布独立 invariant companion。
- 日常和工作目前共用底层对话与工作区目录。独立的模式历史、日常工具、定时计划及连接广场需要相应产品服务接通后，才能与调研参考实现端到端一致。

能力选择用原会话输入修订号调用 `SessionInput.composeReference()` 插入普通前缀文字，保留原子文件及会话引用；切换尚未发送的指令时保留其参数。普通智能体运行中仍可选择草稿；指令提交与判定期间维持短暂输入锁。目录刷新不能向已被替换的会话绑定写入。

已批准作者技能显示“已审核·接单未启用”；只有新鲜清单确认本机资格、保存的逐项授权一致且总开关开启，才显示“接单已开启”。商品上架状态单独显示，并说明缺销售资料或显式买断售价。用户点击启用接单才调用现有 Host 启用流程；刷新和渲染不会安装或投稿。缓存或不可用的资格不能显示接单已开启，也不能授权操作。

可选 profile 服务 `qianshouMarketplaceNavigation.openPublications({ source, name })` 打开一个规范本机技能身份对应的现有发布管理。返回 true 只表示请求已接受，不表示投稿存在或已经读取。管理器在页面挂载前只保留最新打开请求，并按请求 ID 消费；旧确认不能清除新请求。消费后保留页面选中的标签和精确来源焦点，卸载使保留的回调失效。导航不会设置价格、发布、批准、购买或启用接单。

每次能力核对只锁定自己的卡片。换选、关闭弹窗或超过可配置的 `abilitySelectionTimeoutMs` 会取消该次选择，迟到目录回执不能写入引用。客户端插件接收 1000–60000 毫秒的整数超时配置，默认 15000 毫秒；核对期间其他可用卡片与刷新仍可操作。等待上限不批准或取消任何收费任务。

本机插件展板使用 `conversationPlugins()`，只读取本机包与 Loader 激活记录，不等待云端投稿、购买权益或设备安装清单。名称优先使用安装包的 `qianshouDisplayName`；市场任务 ID、技能命令和插件标识收在“技术信息”中。刷新保留已有卡片，不使整个来源的按钮变灰；选择时仍重新核对当前本机状态，仅当前核对项等待，未取得真实工具回执不声称执行。

只有符合生成器精确 32 位十六进制后缀的 `qianshou-local-` 包名，卡片才从公开说明取简短标题；无可读标题时显示本地化的“本机插件”。人工名称保持原样；技术信息、借用草稿与 Host 选择保留原始名称及标识。

接单页的 H3 配置卡片仅在用户展开后读取当前已登录账号和实际 profile。机主选择已有的模型、工作流、首帧、运行程序，以及适配器实际保存视频的目录。检查和保存不会生成视频；明确点击本机测试才生成五秒视频，不收取平台费用。处理中或结果未知的测试不会自动重跑。本机测试通过后可以创建本地技能草稿，平台核验、发布与设备接单授权仍需分别完成。Host 为确切账号、profile 和配置版本签发不含身份字段的配置上下文；测试和草稿指令复用该上下文，不接受调用方指定账号。账号变化立即清空卡片，迟到回调不能恢复旧选择或测试证据。页面不显示私有路径和原始报错细节。

接单页先汇总 Host 返回的所有已安装能力，将本机可授权能力与待补接单条件的能力分开计数；清单不完整或读取失败时，两项数字均显示未知。具体模型的接入方式排在通用清单之后。用户打开 H3 卡片后，才会看到 ComfyUI 与 H3 服务、五类模型、插件和四步工作流的安装要求。页面状态只表示整套服务身份曾通过本次检查，或本机此前两次真实出片已核验；它不会猜测具体缺少哪个文件，也不代表当前可接单。配置保存后若没有本次检查，显示仍为“待核验”。目前没有经过核验的签名下载源，因此页面仅给人工安装指引，不会自动下载软件或开启接单；选择已审核的视频接单来源时，Host 仍会重新核验已安装执行器。

接单能力只显示「工具、图、文」三个浏览分组。原有分类与接单资格元数据保留，旧视频工具仍可在工具组找到。数量来自已安装清单，不假定 64 个工具均已核验；再次点击同一组恢复全部。一个按钮前往算力共享，手工 H3 配置折叠为旧版诊断。
