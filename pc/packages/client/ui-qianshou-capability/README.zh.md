# @deepseek-ai/dsh-client-ui-qianshou-capability

[English](README.md) | 中文

## 概述

千手构建会在「设置 → 高级」增加一个分区，显示调度中心列了哪些能力、选中的那条有多少工人应答、以及服务端估算跑一次要多少钱。其他 profile 在 `apply` 里直接返回，不注册文案、不注册插槽、不挂监听，因此别的构建既不带这个分区也不带它的 Remote 依赖。每一次请求、每一个数字、每一个失败名字都由 [Host](../../host/qianshou-capability/README.zh.md) 决定；本组件只负责把读到的东西显示出来。

## 用法

分区挂载时读一次目录，重连之后再读一次 —— 窗口断开期间 Host 可能已经登录了。选中一条能力，只读这条能力的调度计数。估算是一次显式的表单提交：必须填目标，本地预算上限可以不填。这里的任何操作都不会生成报价、不会预占资金、不会提交工作负载。

分区名称为“算力诊断”。本地无法估算不表示另一个市场调用合同被拒绝；文案引导用户通过 @ 或对话技能展板请求当前报价，不宣称任何特定市场能力可调用。

三次读留在三个字段、屏幕上分三块。换选中项会清掉上一条的应答与估算，而不是把它们挪到下一条能力上；被更新的选中项作废的应答会被丢弃，不会渲染出来。本地注册表里没有落地任务类型的能力照样列出来，但估不了：估算按钮保持禁用并说明原因。

四种结果互不混淆、各有各的措辞：没有会话、目录为空、服务端具名失败连同 HTTP 状态、以及 RPC 本身失败。首次 RPC 失败会以错误状态取代加载提示；刷新失败则保留上一次真正读到的目录，并在旁边显示警告。读取限流这个失败有自己的文案，绝不会被当成"读取中"指示。

## 模型体验

### 能力读取

#### 模型看到什么

`qianshouCapability` 分区不注册任何工具，也不往提示词里加内容。打开它、刷新目录、选中能力或请求估算都不发送用户消息，也不往会话里加任何东西。

#### Token 影响

这些读取不消耗模型 token。估出来的金额描述的是服务端为一次预期工作负载定的价，不是模型用量。

#### KV Cache 影响

这个分区不修改会话历史，也不修改任何模型提示词前缀。

## 已知限制与延期事项

<a id="doc-section-3"></a>

- 金额按服务端发来的原样渲染，不做本地算术、不换汇、不取整；货币字段收的是自由文本而非校验过的代码表。面板不能提交工作负载，所以从估算走到真跑一次这条路在这里没有走通。组件测试用替身驱动 Remote；来自已部署调度中心的目录条目、工人计数与价格需要在运行的应用里验收。不发布运行时不变量伴生包 —— 本组件只持有 Host 状态的可丢弃视图。
