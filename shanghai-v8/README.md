# 上海 V8 控制引擎

这是千手分布式边缘算力项目的控制面源码快照。其原创部分由胖墩开发，按本目录的 [PolyForm Noncommercial 1.0.0](LICENSE) 提供非商业用途；商业使用请参阅 [商业授权说明](COMMERCIAL-LICENSING.md)。仓库中的其他组件各自遵循原有许可。

引擎负责账号、任务定义、切片与聚合、节点匹配、调度、派发、租约、验证与账本。媒体文件交换不经过上海；图像和视频的媒体通道由广州承担。源码中有 74 种静态任务定义和 12 组切片／聚合实现，这只是代码盘点结果，不表示所有任务都经过跨设备实机验收。

Python 包位于 `platform_v8/`：`core/` 是实体与状态；`engine/` 是调度与 broker；`services/` 是业务逻辑；`api/` 是 HTTP/WebSocket；`storage/` 是持久化；`migrations/` 是数据库迁移；`tests/` 是离线测试。公开候选从现网源文件冻结，再剔除运行配置、私有凭据和操作脚本；它不是可直接替换生产实例的部署包。

当前候选还在做安全和可重建验收。旧版 README 中的生产数据库删除、直接公网启动等命令不属于安全的本地开发步骤，因此不随公开候选提供。运行测试时应先使用独立数据库和 Redis，在隔离环境安装依赖，不能对现网执行迁移或覆盖部署。正式可复现安装步骤会在依赖锁与全量测试完成后补齐。
