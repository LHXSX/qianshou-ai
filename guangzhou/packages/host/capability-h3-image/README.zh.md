# H3 图像能力参考夹具（可选）

[English](README.md) | 中文

## 概述

这个包不是千手产品默认能力，也不提供 H3、图片或任何模型。它只是一个可选的测试夹具，用来验证“节点自带能力 → 节点智能体上报 → 调度中心按精确版本匹配 → 智能体调用本机执行器”的通用接缝。夹具声明 `image.generate@1.0.0`，生成有边界的提示词，并把注入的本地渲染器接入算力执行器契约；它只返回受控工作目录内的 SHA-256 输出引用。

## 用法

仅在测试或节点适配器开发中，使用已验证安装计划授予的权限调用 `createH3ImageExecutor`，并传入节点自有的 `render` 实现，再把返回值注册到 `ComputeExecutorRegistry`。渲染器负责本机模型调用，并且只能写入请求提供的受控工作目录。千手不会安装、托管或承诺这项能力。

<a id="model-experience"></a>

## 模型体验

测试智能体可以从节点提供的清单发现精确的能力版本，生成稳定提示词封装，报告 `prepare` 和 `complete` 阶段，并把带摘要的结果引用交给工件服务；图片字节不会经过宿主控制面转发。该体验不代表千手提供图片能力。

<a id="known-limitations"></a>

## 已知限制

这里不包含模型权重、H3 SDK、云端 API、市场传输、计费或插件加载器。H3 仅作为非产品参考；真实能力必须由节点自行安装、核对并上报，调度中心不能从硬件配置推断能力。

<a id="development-note"></a>

<a id="dev-note"></a>
## 开发备注

保持这个夹具声明式且依赖轻量，不把它加入默认 profile 或 Web bundle。平台适配器应拆成独立包，并保留无人干预执行、取消、受控工作目录和精确版本选择；新增图片、视频或其他能力时，只增加节点侧适配器与广告，不修改调度核心。
