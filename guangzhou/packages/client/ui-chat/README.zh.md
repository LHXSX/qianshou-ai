# @deepseek-ai/dsh-client-ui-chat

[English](README.md) | 中文

## 概述

使用本包可在浏览器中渲染已记录的 Session 对话，包括历史图片、本地化操作和滚动位置恢复。紧凑显示会收起已完成轮次的过程行，同时保持最终答案和独立有用的上下文可见；已打包的历史 Assistant 连续消息保持收起。本地 transcript（文本记录）与 steering（中途引导）提交会立即显示并保留在原区域，在权威会话记录到达时原子地消失，而排队中的提交始终不进入 Chat。本包不组装或修改模型请求。

文件提及提供方同时接收当前查看的会话 ID 与收尾轮次的属主信息，因此继承历史中的链接可以指向 fork 自身。

<a id="reference-previews"></a>
## 引用预览

已发送的文件引用及消息日志确认调用的 skill 可在右侧栏打开预览。文件路径使用当前查看的 Session；skill 名称由该 Session 当前的输入触发源解析。两者悬停或聚焦时均使用正文文件链接的虚线下划线。会话、目录和命令标签仍只作为引用展示。

<a id="independent-task-receipts"></a>
## 独立任务回执

并行提交成功后，父会话显示已记录的原始消息、图片和文件，并附上独立任务回执。回执刷新后仍保留，即使父会话尚无模型轮次也能显示。用户点击执行记录时才打开已接纳的子任务；收到回执本身不会导航。这些行不参与父轮次过程折叠，也不创建模型消息或 token 用量。未记录原始消息的历史回执只把已保存的标签作为任务摘要显示，不将其冒充原始提交内容。

<a id="system-prompt-row"></a>
## 系统提示词行

每个非空追加的 `system/message` 都拥有一行折叠提示词，包括无 header 窗口起点的完整提示词；同一步骤的 header 不会重复它。Chat 也会为非空的初始请求、显式消息序列起点、文本发生变化的 `system/message` surface 节点替换（文本读取自 `request/header` 处 surface 顺序中最后一个非空存活系统节点），或前序 header 尚未进入已加载历史窗口的非初始请求显示一行默认折叠的 `系统提示词`。即使系统文本未变，恢复也会重复该行，包括分页补齐前序 header 和系统节点后；同一序列内仅配置或仅工具变化、工具步骤与重试不会重复，且 `system/message` 事件绝不会渲染为对话消息。该行位于请求的用户消息之前，与提供方 envelope 顺序一致；展开后显示模型所见的确切文本，并保留其原始换行。系统节点为空或位于已加载窗口之外的请求不创建该行，直到包含该节点的分页到达。

<a id="turn-token-usage"></a>
## 轮次 token 用量

只有当已加载窗口包含 `turn/start`，且每次已启动的模型尝试都报告安全、精确的用量时，已完成轮次才显示可展开的用量行。该行会省略不可用的可选用量桶。记账不完整或相互矛盾时，整个详情都不显示，避免把部分总量冒充完整结果。

<a id="completed-turn-footer"></a>
## 已完成轮次的页脚

已完成轮次的操作页脚位于前方正文或扩展内容下方 20px。

Session 运行时，小机器人在原有状态行内运动，旁边保留本地化的工作提示。计时仍以 `turn/start` 为起点，15 秒后显示，不加入实时播报。运行结束时机器人消失，减少动态效果偏好下保持静态；动作只表示正在工作，不表示完成百分比。详见[状态图标决策](../../../.agents/notes/implemented/feature/2026-09-14-working-robot-status.zh.md)。

<a id="turn-process-folding"></a>
## 轮次过程折叠

「设置 → 通用设置」提供持久化到 `ui-chat` 命名空间的「专注」/「标准」/「紧凑」对话显示偏好，默认使用「紧凑」。标准模式保持所有过程行可见且不渲染轮次过程控件。紧凑模式下，系统提示词在整个轮次中始终独立显示于开场 User 上方。轮次打开期间，上下文注入、推理、Assistant 内容、工具行与重试行始终展开。到 `turn/end` 时，最后一个步骤只有在包含非空文本、图片或未知可见块且不含工具调用块时才成为最终答案边界；边界之前的上下文注入、推理、较早 Assistant 内容、工具行与重试行随后默认收起。控件展示覆盖整个轮次的非 subagent 工具调用数、最终答案之前带回复内容的 Assistant 消息数和 subagent 委派数；值为 0 的分段省略，工具调用与 subagent 两项互斥，系统提示词与上下文注入都不增加计数。三项全为 0 时过程仍会收起，控件标题显示「已思考」（英文为 `Thought for a while`）。紧凑的带边框摘要将过程与正文隔开。用户与 steering 消息、系统提示词、错误、最大 token 与 turn-tail 行留在过程组外；关闭时没有最终答案的轮次保留全部过程证据。新的过程控件插入时不会改变既有行的相对顺序：开场人工输入从首次投影起便位于控件和过程行之前，系统提示词则始终位于该输入上方。只要仍可通过「加载更早」获取历史，过程控件就不出现，也不会隐藏任何成员；历史加载完整后，每个合格的已关闭轮次立即使用默认收起状态。稳定 Chat Node Seat 会让每个 renderer 保持挂载，隐藏成员不产生消息流间距；只有中间没有独立输入时，收起控件才与正文相隔 8px。完成后的收起不依赖是否跟随尾部，因此正在上方阅读的用户可能看到 transcript 重排。若自动收起会隐藏当前键盘焦点，则过程组保持展开且焦点留在原处；手动收起会先把焦点移到过程控件，再隐藏成员。会话作用域存储只记录用户手动展开的「轮次 + 正文步骤」generation；不同正文 generation 默认收起。

专注模式也会整理执行中的内容：最新的可见 Assistant 回复、人工输入、派工回执和失败的工具调用保持可见，较早的进度与普通工具调用收进过程摘要。手动展开的运行中过程会跨步骤保持展开，完成后使用正常的最终答案边界。最新回复从当前 Node 集合投影，避免复用的位置对象隐藏新回复。推理行使用稳定的本地化标题，展开后展示原始内容；工具行显示真实的运行中、已完成、失败或中断状态。这些显示偏好不改变模型请求、任务执行或对话持久化。

<a id="scroll-ownership"></a>
## 滚动归属

Chat 会在历史前插与 renderer 重新挂载时恢复语义锚点。没有读者移动的贴底滚动事件会立即更新跟随归属，避免后续布局变化使其底部位置失效。读者移动即使位于跟随阈值内，也保持待处理直到采样周期或 `scrollend`，防止布局增长抵消小幅滚动操作。读者跟随底部时，`ResizeObserver` 追随新的底部，并且无需读取行几何就选中最后一个已加载轮次；读者离开底部后，高度变化会保持顶部位置，再由阅读线几何选择活跃轮次。轮次导航预览位于 Markdown 代码块粘性头栏上方，而导航外框始终处于 composer 上方的 transcript 区域内。

<a id="voice-collaboration"></a>
## 语音协作

输入框下的语音按钮只在用户明确点击后开启麦克风。本地按停顿分句，将每段音频以 16 kHz、单声道 PCM16 WAV 交给已认证的同源 `/api/forge/voice/transcribe`。默认“语音管家”把识别原文交给当前 Session 的输入机：空闲时以 queue 投递，运行中以 steer 补充。所选主智能体结合已记录的对话和现有工具进行交流、澄清、委派与跟进；浏览器不分类意图，也不注入隐藏指令。提交后恢复聆听，用户可以在任务运行期间继续说话。文字输入框的投递方式独立保留。

用户可明确选择“并行派工”，通过已有派工接口创建独立任务；“补充当前任务”则等待当前轮次结束后再朗读。选中可续跑子任务时使用当前任务投递，不会暗中把语音转到另一会话。播报只读取实际观察到的已结束轮次最终答复；用户说话时保留待播答复，不朗读中间推理。它直接订阅所选轮次的尾部数据源，因此尾部数据发布不依赖顶层 Chat 快照变化。用户可以打断朗读继续说话，工具和审批仍显示在原对话中。

听写只追加草稿，不自动发送。自动提交前会检查草稿版本、引用、附件、审批和输入限制。结束语音或切换 Session 会释放采集并取消转写和朗读；已提交工作继续遵循原有 Session 生命周期，另有停止操作。转写和播报失败会暂停语音并显示本地化错误。浏览器语音合成不可用时仍可使用听写。已完成的助手回复另有独立朗读和停止按钮。设计依据见[具备上下文的语音管家决策](../../../.agents/notes/implemented/feature/2026-09-13-contextual-voice-concierge.zh.md)。

播放会查询已认证的本地[神经语音端点](../../host/voice-local/README.zh.md)。神经模型资源可用时，使用其配置的 Vivian 或 Serena 预设；先合成有实质内容的短首句，再把后续短句合并为有界语段。实际播放开始后，最多预取下一个 WAV，使合成与当前播放重叠，但不启动第二个播放器。仅在尚未选择神经声线，且状态明确不可用或状态路由缺失时，才使用浏览器语音；存在中文 Tingting 时优先使用。已选择或已实际播出的神经声线在同一窗口后续回复和手动朗读之间保持一致。该声线随后不可用时显示失败，不会切换语音引擎。系统声线列表初始为空时最多等待 600 毫秒，并为整条回复固定一个声线；若仍无可枚举声线，则使用一次 utterance，避免逐句重选变化中的浏览器默认声音。认证、神经合成或音频播放失败保持可见，不会静默更换声音。取消会中止待完成请求、停止媒体并释放对象 URL；延迟响应不能重新开始播放。合成或播放启动等待期间，控制器显示“正在准备声音”。只有实际媒体 playing 或系统语音 start 事件才使其切换为“正在朗读回复”。此完整 WAV 路径不保证流式首声延迟。

播报期间，只有已获取音轨通过 getSettings 确认回声消除已启用，才通过连续麦克风声音检测自动打断。确认开口后停止当前回复，并保留开头音频继续转写。回声消除为 false 或未报告时，播报期间采集保持静音，界面说明手动打断方式。输入文字或添加附件会暂停语音并保留草稿，由用户自行发送；打断不会停止任务。取消的回复与排队的旧回复不会在恢复后补播。这些本地启发式逻辑已通过确定性 PCM 和生命周期测试；实体麦克风、扬声器和房间声学仍需设备现场验收，不承诺完整的双工声学效果。见[播报打断决策](../../../.agents/notes/implemented/feature/2026-09-13-voice-playback-interruption.zh.md)。

虚拟形象通过只读 speech-playback 订阅观察声音。真实句段开始时带有独立播放标识，结束、取消与失败会终结该标识。播放中途订阅会同步收到最近一条仍活跃的开始事件。神经语音事件提供现有媒体元素和已验证 WAV 的副本，可用于本地分析，无需接管音频输出或采集麦克风。系统语音只提供播放状态，不伪造 PCM；无法分析波形时，角色保持闭嘴，待机姿态独立运行。

活动语音控制器伴随全身 VRM 角色显示在透明、非模态舞台上。画布允许点击穿透至工作台；紧凑控制条持续提供状态、处理或播报期间的打断入口以及结束语音操作。语音设置收在“更多语音控制”中，并持续挂载。暂停错误和恢复控件自动展开，不移动键盘焦点。暂停会禁用麦克风轨道并取消待完成转写或朗读，不停止已接受任务；继续聆听需明确点击。

自动回复、手动朗读和试听共用独占音频所有权。开始新播音会取消旧播放器及排队语段，并让旧朗读按钮回到空闲。此取消不报告完成：其他入口的播音会暂停采集，并取消待执行的麦克风恢复定时器。已接受任务继续运行。声线选择器保留暂不可用的选择，允许用户主动替换。延迟返回的声线列表会读取当前偏好，临时状态失败不能清除控制器的选择。试听不会替换最近实际播出的回复声线。见[声线保持决策](../../../.agents/notes/implemented/bug-fix/2026-09-14-preserved-voice-identity.zh.md)。

试听声线会先暂停麦克风采集并取消当前回复，再开始合成。“正在准备试听”与实际播放分开显示；只有媒体 playing 事件才发布共享的只读 WAV 观察事件。停止试听、更换声线、恢复采集或结束语音都会取消当前播放器并结束其播放标识。试听完成后保持暂停，需用户选择“继续聆听”，避免试听音频被自动提交为用户话语。回复播报和试听共用有界 WAV 读取器。

拖动手柄或使用方向键可在视口内移动，Shift 加大步幅。动作菜单提供招手、沿底部走动、沿两侧边缘攀爬、靠边和坐下。移动只在明确选择后开始，并遵循减少动态效果偏好。Escape 停止移动、收起已展开的控件并将焦点归还展开按钮，不结束语音。角色移动不会开启麦克风、提交模型请求或操作系统。角色模型从本地延迟加载；加载及失败状态保持可见，“重试”重新加载模型，不打断语音。

<a id="model-experience"></a>
## 模型体验

无，因为本包在浏览器中渲染已记录的对话状态，不注册任何面向模型的内容。

无；Chat 呈现不会组装或修改提供方请求。

## 已知限制与暂缓事项

<a id="known-limitations-and-deferred-work"></a>

- **transcript 只反映已加载的 Session 窗口**——只有会话控制器加载前一页事件后，更早的 transcript node 才会出现。轮次导航比窗口更宽：轨道把已加载的轮次与宿主 `turnOutline` 投影合并，每个已开始的轮次都有固定间距刻度（相隔 10px；阶梯高于外框时在框内滚动并以渐变淡出标示可滚方向），激活未加载刻度会先把历史分页拉到该轮次的 `turn/start` seq 再落到它的行上。没有该投影时（未挂载 `dsh-session-turn-outline` 的装配），轨道回退到仅显示已加载轮次。
- **导航预览按卡片尺寸截断**——提示词一行（50 字符）、回复至多三行（120 字符），已加载与未加载 Turn 一致；未加载 Turn 的回复要等该轮落定后才随大纲到达，进行中的轮次在此之前只预览提示词（或仅轮次号）。
