# 千手模型路由控制台

[English](README.md) | 中文

## 概述

**模型路由**设置一节是管理员对宿主模型网关的控制台。它显示前台名字目录（用户看到的名字）、每个名字的全量绑定历史（含已失效的）、以及可选后端键位。它只有一个写操作：**追加一条未来生效的绑定**；已有绑定永不被编辑。

控制台不会把上游模型标识（`deepseek-flash`、`deepseek-v4-pro` 等）渲染成用户可见文案。管理员看到的是后端**键位**（`flash`、`pro`）及其并发上限这类运维信息，并明确标注用户看不到这一层。

## 使用本包

在支持的 profile 里把浏览器半边挂在模型网关宿主行旁边；它在 `settings.section` 槽位注册 `routing` 一节（顺序 20，排在「模型」之后）。它复用客户端的 React 应用、共享控件、主题令牌与文案服务。

同一插件还在设置里注册独立的 `plugin-review`「插件审核」一节（顺序 21），展示上海待审核投稿的作者、类型、价格、设备要求和无法上架的具体原因。管理员填写审核原因后可通过或退回投稿；界面调用宿主鉴权的 `/api/qianshou/ai/admin/marketplace` 代理，最终是否上架由上海服务决定。现阶段价格与分成只读。

刷新向 `POST /api/qianshou/ai/admin/names` 发请求，并且只渲染响应里真实存在的内容：`names`（记录加 `history`）、`backends`（`key`、`id`、`concurrency`），以及解析器同样接受的另一种形状——顶层 `bindings` 数组。结构不认识的响应会被整体拒绝：控制台显示「数据不完整」，绝不把半个目录当作有效事实。接口没有给出历史的名字保持空历史，控制台会说明这一点，而不是替它编一条。

追加向 `POST /api/qianshou/ai/admin/bind` 发送 `publishedName`、`backendKeys`、`effectiveFrom`、`reason` 与 `rolloutPercent`。请求体里**故意没有** `operator`：宿主按已验证的会话填入，客户端自报会直接毁掉追责链。

失败按原因分别呈现，不合并成一句话。`401` 是「未登录或登录已失效」；`403` 是「当前账号不是管理员」；`400` 原样显示宿主给的中文原因，因为那句话才是管理员能据以行动的信息。

<a id="understand-the-implementation"></a>
## 实现说明

- `src/client/route-catalog.ts` —— 无 React 的核心：响应校验、绑定历史投影、追加表单校验、有序键位编辑、灰度边界与本机时刻换算。所有「请求发出前就必须成立」的规则都在这里。
- `src/client/controller.ts` —— 在注入的 `fetch` 上做一次目录读取与一次绑定追加，并把状态码翻译成失败分类（`not-signed-in` / `forbidden` / `invalid` / `request-failed`）。
- `src/client/RoutingConsoleSection.tsx` —— 面板：目录卡片与每个名字的历史、后端键位表、带生效预览的追加表单。
- `src/client/locales.ts` —— 中文文案（权威）与英文对照。
- `tests/` —— 纯逻辑、控制器、面板与插件装配四组规格测试。

<a id="design-rules-the-ui-must-not-drop"></a>
## 界面不得丢掉的规则

1. **只追加。** 没有「编辑现有绑定」控件。改写绑定会让过去的账单不可解释，所以控制台只提供一个写入口：新增一条未来生效的绑定。
2. **绝不在计费周期中间换绑。** 没有「立刻生效」。生效时刻是显式选择（24 小时 / 3 天 / 7 天 / 自定义），预览会写明具体哪一刻；过去时刻在**发请求之前**就被挡住，并说明「必须晚于这个名字上一条绑定（…）」或「必须在将来」。
3. **后端是有序列表。** `backendKeys` 不是单个键位：主用在前面作答，打满后按顺序落到备用。表单直接编辑这个顺序（上移、下移、移除、追加）。
4. **灰度确定且有界。** `rolloutPercent` 是 0 到 100 的整数；`0` 表示这条绑定先不接流量，`100` 表示全量接手。分流由宿主按名字与请求标识确定性计算，同一个用户的相邻请求不会漂移——面板如实说明，不暗示随机。
5. **状态如实。** 未登录或非管理员时只显示那一句可行动的说明，且不显示任何目录内容；控制台绝不把过期目录当有效事实保留。

<a id="model-experience"></a>
## 模型体验

没有模型可见内容。本浏览器插件只贡献一节面向管理员的设置页；不注册工具、提示词区段或会话事件。

### Token 影响

不影响 token。

### KV Cache 影响

不影响 KV cache。本包既不组装也不发送提供方请求。

<a id="known-limitations-and-deferred-work"></a>
## 已知限制与后续工作

- 控制台只做**读取与追加**：不登记新的前台名字、不改某个记录的档位或输出上限、也不退役名字。宿主没有这些路由，所以这里也不放这些控件。
- 灰度按绑定编写，不按请求人群；没有灰度看板，也没有按后端的错误率视图。
- 生效预览使用浏览器时钟与本机时区，是显示上的便利；是否接受由宿主时钟决定。
- 面板行为在 jsdom 里用「与宿主同形状」的夹具响应验证。不包含对真实网关的浏览器端到端运行；要把这一节装进正在运行的 bundle，仍需补 bundle 行并重新构建。

<a id="dev-note"></a>
### 开发备注

本包不发布 runtime invariant companion。授权（fail-closed）、只追加规则与生效时刻下限都由宿主半边负责；客户端镜像这些规则只是为了尽早失败并显示原因，绝不把自己的校验当作授权。
