# 千手智能体 0.2.1 预览版

此下载为 macOS 13.5 或更新系统的 Apple Silicon 主控端；可选 MLX 神经语音需 macOS 15 或更新系统。主控内含 Electron、Node.js、pnpm、完整 Harness 运行时和千手界面，无需源码目录或另装 Node。底层引擎保留上游版本 0.1.5-rc.2，千手产品版本为 0.2.1。

1. 解压 ZIP，将千手智能体.app 移到“应用程序”，然后打开。本预览版采用临时签名，尚未经 Apple 公证。如果 macOS 阻止打开，请确认来自官网下载页，再使用“系统设置 → 隐私与安全性 → 仍要打开”；不要全局关闭 Gatekeeper。
2. 在应用内配置自己的模型接口和 API 密钥，安装包不附带账号或密钥。已有千手数据继续使用 `~/.local/share/qianshou-agent/home`，新用户从空白配置开始。应用在 3081 端口启动本机服务；端口冲突会明确报错，不会停止其他程序。
3. 先发送一条文字任务。系统朗读可使用 macOS 已安装声音；麦克风识别和 Serena 神经语音需额外本地资源：显示应用包内容，按 `Contents/Resources/app/voice/README.zh.md` 安装。资源另行下载，预览版不会静默下载模型权重。
4. 另一台电脑需下载对应系统的千手协作端。在主控“设备”中创建配对邀请，对方输入邀请、确认主控身份并授权本机工作目录。两端保持开启。远程桌面还需双方单独安装 RustDesk；配对不会自动开放全部文件或安装 RustDesk。

主控仅绑定 127.0.0.1。局域网或公网协作应通过经过身份验证的 HTTPS/WSS 服务或可信 VPN 提供可达的协调地址，再把此地址用于邀请；对方电脑上的 `127.0.0.1` 指向对方自己。不要向互联网开放无认证端口。

官方下载页另有 Windows x64 主控下载，本版不提供 Linux 主控。Windows 主控尚未在 Windows 实机启动验收。Windows/Linux 协作端已做结构及校验和验证，尚未在目标系统启动验收。示例 VRM 角色用于验证交互动作，不代表最终定制角色美术。神经语音耗时取决于本机硬件，且不包含模型思考时间。

应用内保留 DeepSeek MIT 许可证及依赖许可证。运行时版本和包清单位于 `Contents/Resources/runtime/versions.json` 与 `Contents/Resources/RUNTIME_PACKAGES.json`。删除应用不会删除用户本地数据。换版本前请备份，不要让两个主控同时使用同一数据目录。

每位使用者都需要配置自己的模型接口与 API 凭据。公开应用不包含共享 LLM 密钥或模型额度；CEO、员工和自动模型路由都使用该用户配置的接口，缺少凭据时不会回退到运营方账号。

## 应用内更新

通过“帮助 → 检查软件更新”查看版本。应用启动完成后会在后台检查，发现新版后下载并验证官方签名与安装包。下载不会中断现有任务；CEO、员工、后台进程或协作任务尚未结束时不能重启。界面显示“新版已准备好”后，点击“重启升级”生效。更新保留会话、项目、接口配置和自己的 API 密钥。

0.2.1 是带有此更新入口的首个版本，旧版需先从官网正常安装一次。之后无需每次重新手动下载。断网、取消下载或校验失败时继续使用当前版本；新版一旦开始读取用户数据，不会自动退回旧版。
