# 千手智能体 — Windows 快速入门

[English](QUICK_START.windows.md) | 中文

本指南适用于产品版本 0.2.1 的 Windows x64 主控预览版。ZIP 内含 Electron、Node、pnpm 与工作台运行文件，无须另装 Node 或准备源码目录。主控用于与 CEO 对话、管理任务；接收远程工作的另一台电脑安装独立协作端。

## 开始前

目标系统为 x64 处理器上的 Windows 10 或 Windows 11。[Electron 44.0.0 的平台要求](https://github.com/electron/electron/blob/v44.0.0/README.md#platform-support)规定 Windows 10 及以上；本包不提供 Windows ARM64 或 32 位程序。这是未签名的便携预览版。Windows 真机启动、麦克风、扬声器和远程控制尚未完成验收，下载入口对本平台标记为未验证。

云端对话需要你自己的受支持模型 API 凭据。项目用到的 Git、OpenSSH、GitHub CLI 和语言 SDK 需按任务需要单独安装。应用不提供账号、API 额度或凭据。

## 打开主控

1. 在[官方下载页](https://qianshousuanli.com/#/downloads#qianshou-agent)的主控端区域下载 `qianshou-agent-0.2.1-win32-x64.zip`，运行前核对页面提供的 SHA-256。需要主工作台时，请不要误下载 Windows 协作端。
2. 使用“全部解压缩”，将完整的 `qianshou-agent-0.2.1-win32-x64` 文件夹保存在可写的本地目录，打开其中的 `QianshouAgent.exe`。建议选择 `C:\Qianshou` 等较短目录，避免多层嵌套触发 Windows 路径长度限制。不要在 ZIP 内直接运行，也不要只复制 EXE，否则会缺少运行文件。可以为解压后的 EXE 创建快捷方式。
3. Windows 可能提示发布者未签名。请先核对官网来源和校验值。如果设备策略阻止未签名应用，请通过管理员批准的流程处理；应用不要求关闭 Windows 安全防护。
4. 在设置中配置服务商和模型，选择工作区，再发送一个文字任务。确认主会话显示你的原话、执行记录和最终回复。窗口打开成功，不代表 API 凭据或工具访问项目的权限已经验证。

主控使用 `127.0.0.1:3081`。端口被占用时，应用会报错并保留已有服务。请完成工作后关闭另一个主控，或配置其他允许的本机端口；3080 为保留端口。运行 EXE 不会开启公开网络监听。

## 开发、语音与其他电脑

Windows 命令任务使用既有 PowerShell 执行器：显式配置的可执行文件优先，其次检测 PowerShell 7，最后回退到 Windows PowerShell 5.1。此执行器不要求安装 WSL 或 Git Bash。如果项目明确依赖 CMD、Bash 或其他 SDK，请告诉智能体；安装工作台不会同时安装这些工具。PowerShell 5.1 向原生命令传递非 ASCII 输入时可能出现编码问题，请结合所选终端验证此类任务。

请先使用文字对话。系统朗读取决于 Windows 已安装且语音 API 可用的声音。本 ZIP 没有即装即用的 Windows 语音识别资源，也没有 MLX 安装器；连续麦克风对话和听写需要单独配置兼容识别器。详见 [Windows 语音指南](voice/README.windows.zh.md)。打开麦克风或看到动态角色，不代表识别或播报已经可用。包内 3D 角色是功能示例，并非已经完成的定制造型。

远程工作时，在主控的设备页面创建配对码，将协作端下载地址和配对说明发给另一台电脑的使用者。对方安装匹配系统的协作端，填写可达的主控地址及配对码，再授权工作区和所需访问权限。屏幕、鼠标和键盘控制还需要参与设备单独安装并配置 RustDesk，以及远端使用者授权。配对本身不会授予桌面访问权限。

`127.0.0.1` 指向正在使用该地址的电脑，不能把它作为另一台设备的连接地址。局域网或公网协作需要可达且经过认证的 HTTPS/WSS 地址，例如在网络或 VPN 上正确配置的 HTTPS 网关。请保密配对码并检查有效期；复制邀请不代表对方电脑一定能够连通。

## 数据、更新与故障处理

默认数据目录为 `%USERPROFILE%\.local\share\qianshou-agent\home`。替换或移动解压后的应用时，原数据仍保留在此目录。本机桌面配置位于 `%USERPROFILE%\.local\share\qianshou-agent\desktop\config.json`；可用 `QIANSHOU_HOME` 或配置中的 `home` 选择其他数据目录。即使存在旧源码或 Node 路径覆盖，分发应用也始终使用包内运行时。

更新时，先完成活动任务并退出主控，将新 ZIP 解压到独立文件夹，再运行新文件夹中的 EXE。更换版本前，请私下备份数据目录，不要让两个主控同时使用同一数据目录。删除解压后的应用文件夹不会删除数据目录。退出只终止该主控启动的后端进程树；Windows 退出清理无法确认时会明确报错。

启动失败时，请保留错误信息和应用显示的日志路径。日志位于 `home\desktop-logs`；虽然认证 URL token 已脱敏，分享前仍需检查项目内容。缺少运行文件时，通常需要重新完整解压 ZIP。帮助菜单可打开包内使用和语音指南。许可证与运行时清单位于 `resources`，包括 `runtime\versions.json` 和 `RUNTIME_PACKAGES.json`。

每位使用者都需要配置自己的模型接口与 API 凭据。公开应用不包含共享 LLM 密钥或模型额度；CEO、员工和自动路由使用该用户配置的接口，缺少凭据时不会回退到运营方账号。

## 应用内更新

通过“帮助 → 检查软件更新”查看版本。应用启动完成后会在后台检查，发现新版后下载并验证官方签名与安装包。下载不会中断现有任务；CEO、员工、后台进程或协作任务尚未结束时不能重启。界面显示“新版已准备好”后，点击“重启升级”生效。更新保留会话、项目、接口配置和自己的 API 密钥。

0.2.1 是带有此更新入口的首个版本，旧版需先从官网正常安装一次。之后无需每次重新手动下载。断网、取消下载或校验失败时继续使用当前版本；新版一旦开始读取用户数据，不会自动退回旧版。
