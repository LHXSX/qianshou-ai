# Windows 语音说明

[English](README.windows.md) | 中文

Windows 0.2.1 主控预览版无需本地语音模型即可使用文字对话。只有 Windows 向浏览器语音 API 提供可用声音时，系统朗读才可使用。本次发行尚未在 Windows 真机验证扬声器和麦克风表现。动态角色是交互展示，不是语音识别引擎。

## 可用条件

| 能力 | 本预览版的使用条件 |
|---|---|
| 文字对话与任务派发 | 配置模型服务商及所需工作区权限，不需要语音模型。 |
| 系统朗读 | Windows 已安装且语音 API 可访问的声音，以及正常音频输出。不同电脑的声音选项可能不同。 |
| 听写与连续麦克风对话 | 单独安装兼容的本地识别资源，并获得麦克风权限。ZIP 不含这些资源或 Windows 安装器。 |
| Serena/Vivian 神经语音 | 已配置的兼容本地 worker 和模型。不提供 Windows worker 安装流程；Apple Silicon 的 MLX 安装器不适用。 |

识别使用主控经过认证的本地转写服务，不会自动回退到浏览器 SpeechRecognition 或云端识别。对话模型的 API 凭据不会启用语音识别。打开语音控制时，应用不会下载语音模型权重。

## 检查系统朗读

1. 打开主控，配置对话服务商，并获得一条文字回复。
2. 打开语音控制，选择可用的系统声音。试听或使用回复的朗读按钮，确认所选声音能正常播放，停止操作能结束播报。
3. 没有系统声音或播报失败时，检查 Windows 的语言与语音设置、音频输出设备及音量。更改已安装声音后重新打开应用。列表出现某个声音，不代表该声音已在本机播放成功。
4. 检查语音时继续保留文字对话。如果提示本地识别不可用，不要反复授予麦克风权限；权限本身无法补齐缺少的识别器。

## 识别与权限

部署维护者可通过 Host 的绝对路径设置，或启动器默认环境变量 `FORGE_WHISPER_BINARY` 和 `FORGE_WHISPER_MODEL`，指定可信且兼容 Windows 的 whisper.cpp 可执行文件及模型，两个文件都必须存在。默认 POSIX 路径不是 Windows 安装结果，重命名 Mac 程序也不能使其兼容。编译和安装 Windows 识别器不属于本包提供的安装流程。

维护者配置并验证识别资源后，请先完成活动任务，再重新打开主控以读取资源路径。在 Windows 的“隐私”或“隐私和安全性”设置中启用麦克风及桌面应用麦克风访问，再允许应用的音频请求。说一句短话，确认转写内容后再派发任务。需要在该设备上验证监听、打断、取消和输出；资源可用检查不代表识别准确性或麦克风权限已经通过。

Electron 桌面端只允许可信主页面采集音频，不能替你授予 Windows 系统权限。其他云端服务商或远程协作端不会免除本机权限要求。报告语音问题时，请避免分享录音或应用凭据。

## 安装范围

本 Windows 包只包含这些说明，不包含 macOS 的 `install.py`、Homebrew 命令、Python wheel 包或 MLX 模型安装器。请不要在 Windows 上照用 Mac 语音指南。已有用户数据、声音偏好和显式 Host 配置继续生效，预览版不会用 Windows 预设覆盖它们。兼容本地资源配置并检查完成前，请使用文字对话及可用的系统声音。启动、数据和协作端说明见 [Windows 快速入门](../QUICK_START.windows.zh.md)。
